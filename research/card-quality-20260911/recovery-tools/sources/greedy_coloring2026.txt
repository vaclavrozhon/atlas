                                                                                    Abstract
                                            A d-defective c-coloring of a graph G = (V, E) is a coloring of the nodes V with c colors such
                                        that every node has at most d neighbors of the same color. Distributed algorithms for computing
                                        different variants of defective coloring are at the core of most deterministic state-of-the-art
arXiv:2608.02386v1 [cs.DC] 3 Aug 2026




                                        distributed coloring algorithms, and they are also an important tool in many other distributed
                                        graph algorithms. In several cases, the overall complexity could be improved if some version of
                                        defective coloring could be solved more efficiently.
                                            Presently, the primary challenge in understanding the distributed complexity of defective
                                        colorings is to understand which defective coloring problems can be solved in time O(log∗ n) and
                                        for which such problems one needs Ω(log n) rounds (in n-node graphs if the maximum degree ∆
                                        is treated as a constant). Already Barenboim and Elkin [STOC ’09] showed that for any integer
                                        p ≥ 1, a simple greedy-like algorithm that makes two passes over the nodes can color with p2
                                        colors and defect ⌊∆/p⌋ in O(∆ + log∗ n) rounds. Up to now, this algorithm provides the best
                                        tradeoff between defect and number of colors for any known algorithm with complexity O(log∗ n)
                                        in bounded-degree graphs.
                                            In this paper, we further investigate the power of this greedy-like two-pass algorithm for
                                        computing defective colorings. We first show that the algorithm can be generalized to the list
                                        defective coloring problem as defined by Fuchs and Kuhn in [DISC ’23]. As a consequence of
                                        this, we in particular
                                                     √         get an alternative algorithm for computing a (proper) (∆ + 1)-coloring of a
                                        graph in Õ( ∆) + O(log∗ n) rounds in the CONGEST model. In the second part of the paper, we
                                        study a generalized version of the greedy-like two-pass algorithm for computing standard defective
                                        colorings. We show that if the number of colors c is not a perfect square, we can in most cases
                                        achieve a defect that improves the current state-of-the-art for distributed defective c-colorings by
                                        a constant factor. We however also show that for any c ≥ 1, the√generalized two-pass algorithm
                                        cannot achieve a c-coloring with defect less than (1 − o(1)) · ∆/ c.

1    Introduction and Related Work
Distributed coloring is arguably the most studied problem in the area of distributed graph algorithms.
The task is to color the nodes (or edges) of some n-node graph G = (V, E), which also defines
the network topology. The nodes of G have unique O(log n)-bit identifiers, and they can exchange
messages over the edges of G in synchronous rounds. If the messages can be of arbitrary size, this
setting is known as the LOCAL model [33, 38] and if the message size is restricted to O(log n) bits, it
is known as the CONGEST model [38]. In its standard form, the coloring problem asks for a proper
coloring, where no two adjacent nodes are assigned the same color. The number of allowed colors is
usually some function of the maximum degree ∆. Of particular interest in the distributed setting is
the problem of coloring with ∆ + 1 colors, which is the number of colors used by a sequential greedy
algorithm. The round complexity of distributed (∆ + 1)-coloring is typically either studied as a
function of n or (primarily) as a function of ∆. As a function of n, the best known complexities in the
LOCAL model are Õ(log5/3 n) for deterministic algorithms [23] and Õ(log5/3 log n) for randomized
algorithms [14, 23].1 The best known complexities in the CONGEST model are O(log2 ∆ · log n) for
deterministic algorithms [26] and O(log3 log n) for randomized algorithms [26, 27]. The best known
lower bound is Ω(log∗ n), which holds in the LOCAL model and even for randomized algorithms and
if ∆ = 2 [33, 37]. When considering the problem’s complexity as a function of ∆, a √ log∗ n dependency
therefore becomes unavoidable. In this
                                     √ regime,   the best known upper bounds are O( ∆ log ∆+log∗ n)
in the LOCAL [11, 19, 35] and O( ∆ · log ∆ · log6 log ∆ + log∗ n) in the CONGEST model [20].

Defective colorings. Defective colorings are natural generalizations of proper colorings, which
have become instrumental tools in many modern distributed coloring algorithms and also more
generally in distributed graph algorithms. For integers d ≥ 0 and c ≥ 1, a d-defective c-coloring
of the nodes of a graph G = (V, E) is a coloring of V with at most c colors such that every node
v ∈ V has at most d neighbors of the same color. In the context of distributed coloring algorithms,
defective colorings can in particular be used to design recursive distributed coloring algorithms. A
d-defective c-coloring partitions a graph into c parts of maximum degree d. As the complexity of
many of the fastest distributed coloring algorithms quite strongly depends on the maximum degree,
each of the c parts can be colored more efficiently (in parallel or in some cases also sequentially). In
[34], Lovász showed that every graph of maximum degree ∆ has a defective c-coloring (for any c ≥ 1)
with defect d = ⌊∆/c⌋.2 If defective colorings with these guarantees could be computed efficiently in
the distributed setting, even the most naive implementation of the above recursive coloring strategy
would directly lead to efficient algorithms to color with O(∆) colors.

computing by Barenboim and Elkin [8] and by Kuhn [29]. Both used defective colorings to improve
the complexity of (∆ + 1)-coloring from O(∆ · log ∆ + log∗ n) (cf. [31, 39]) to O(∆ + log∗ n). We

     Defective colorings provide a decomposition of a graph into several graphs of lower degree on
which a given graph problem (e.g., some proper coloring problem) can then be solved more efficiently.
Defective colorings are thus naturally most interesting if we focus on the complexity as a function of
∆ and if we thus restrict the n-dependency to O(log∗ n). Understanding which distributed defective
coloring problems can be computed in time f (∆) · log∗ n for some function f (·) and for which
problems, we need at least Ω(log n) rounds deterministically (and at least Ω(log log n) rounds with
randomization) is therefore currently the most important open problem in the context of distributed
defective coloring and possibly even in the context of distributed coloring more generally. It is known
that d-defective 2-coloring requires Ω(log n) deterministic rounds even if d = ∆ − 2 [5] and that for
d-defective 3-coloring, one needs Ω(log n) rounds whenever d ≤ (∆ − 3)/2. Apart from those hardness
results, it is only known that d-defective c-coloring needs Ω(log n) rounds, whenever c · (d + 1) ≤ ∆ [2].
In [8], it is shown that for any positive integer p, one can compute a ⌊∆/p⌋-defective coloring with p2
colors in time O(∆ + log∗ n). Despite intensive research on distributed coloring problems, for general
graphs, we do not know any O(f (∆) + log∗ n)-round (or O(f (∆) · log∗ n)-round) algorithm with a
better trade-off between defect and number of colors.

Arbdefective Colorings. Because computing defective colorings with a good defect to number of
colors ratio appears to be a hard problem, researchers have considered a relaxed variant known as
arbdefective coloring. In a coloring with arbdefect d, each color class forms a graph of arboricity at
most d. Arbdefective colorings were introduced by Barenboim and Elkin in [9] and they have found
many applications in the context of distributed coloring algorithms and more generally in the context
of distributed graph algorithms (e.g., [7, 9, 11, 17, 19, 23, 24, 26, 30]). A d-arbdefective coloring
can essentially be computed by computing a vertex coloring together with an edge orientation so
that every node has at most d outneighbors of the same color.3 It is known that a d-arbdefective
c-coloring can be computed in q  time f (∆) · log∗ n if and only if c · (d + 1) > ∆ [2]. In this case, the

List Defective Colorings. The state-of-the-art distributed coloring algorithms all rely on the
explicit use of list colorings: In a list coloring instance, every node v obtains a list Lv of colors as
input and as output, each node v has to choose some color from Lv such that the graph is properly
colored. List colorings in particular allow to color a graph in several phases, where each phase
extends a given partial proper coloring of the graph. In order to effectively use defective colorings
in the context of list colorings, we should be able to use the coloring to divide a given list coloring
instance into several (ideally independent) list coloring instances of smaller degree. If we divide the
nodes into subsets of approximately equal smaller degree, we also need to divide the colors into the
same number of parts in such a way that all lists are divided approximately evenly. Without global
communication, it is clearly not possible to partition the colors such that the induced partition of
each of the lists is close to a uniform partition.4 One can however generalize the idea in the following
way. Assume that all the lists Lv consist of colors from some space of size C (say from the set
{1, . . . , C}). One can then partition the global color space into p > 1 parts of size ≈ C/p. This
induces a partition of the lists that is not uniform. As a consequence, each node has to select one of
the p remaining color spaces in such a way that the number of conflicting neighbors decreases at
a rate that is comparable to the decrease of the list size. This color space reduction idea has been
introduced in [30] and it has since then been used in [3, 6, 20, 22, 26]. In [20], it is shown that the
core task that needs to be solved can be phrased as a natural list extension of defective coloring.
Formally, in list defective coloring, each node v obtains a color list Lv together with a defect function
dv : Lv → N0 that assigns non-negative integer values to the colors in Lv . The coloring has to assign
a color xv ∈ Lv to each node v such that the number of neighboring nodes u that get assigned color
xu = xv is at most dv (xv ).

The Two-Phase Algorithm for Computing Defective Colorings. A particularly simple and
in our opinion very natural (distributed) algorithm to compute defective colorings is a two-phase
greedy-like algorithm that was first described by Barenboim and Elkin in [8]. Assume that we are
given a proper coloring of the nodes V of a graph G = (V, E) with q colors. We make two passes
over the nodes. In both passes, nodes of the same color are processed simultaneously. In the first
pass, we process the nodes in the order given by increasing colors and in the second pass, we process
the nodes in the opposite order (i.e., by decreasing colors). The algorithm has as integer parameter
p ≥ 1. In both passes, each node v ∈ V picks a color from {0, . . . , p − 1}. The color xv,1 of the first
pass is chosen as a color that is chosen as the color xu,1 by the least number of neighbors of smaller
input color (i.e., by the least number of previously processed neighbors in pass 1). Similarly, the
color xv,2 of the second pass is chosen as a color that is chosen as the color xu,2 by the least number
of neighbors of larger input color (i.e., by the least number of previously processed neighbors in pass
2). The final color xv of v is computed as xv = p · xv,1 + xv,2 ∈ 0, . . . , p2 − 1 . It is not hard to
                                                                     

see that each node can have at most ⌊∆/p⌋ neighbors that choose the same color. This two-pass
algorithm has later in particular also been used in [5], where it is in particular shown that one can
compute a d-defective 3-coloring in time O(∆ + log∗ n) as long as d ≥ (2∆ − 4)/3.

    The main goal of the present paper is to understand the power of the two-pass greedy approach
to defective coloring problems. For this purpose, we generalize the algorithm in the following way:

    • In the first pass (where nodes are still processed by increasing input color), every node v chooses
      a set Sv of candidate colors. The set Sv is chosen from a set S of candidate sets. The set is
      chosen such that the smallest defect of v when picking the best color in Sv is best possible,
      when assuming that all not yet processed neighbors will pick worst-case colors (from set Sv )
      and all already processed neighbors u will later pick a worst-case color from their set Su .

    • In the second pass (where nodes are processed by decreasing input colors), each node v chooses
      a color xv ∈ Sv that minimizes the worst-case possible defect of node v (when assuming that
      the neighbors u with smaller input color will choose their color xu in a worst-case way from
      Su ). In case of list defective coloring, the color xv of course has to be chosen from Sv ∩ Lv .

   In the following, we will refer to this algorithm as the Two-Sweep Algorithm. A formally precise
description of the algorithm is given in Section 3.1. We next give an overview of the technical
contributions of the paper.


2     Our Contributions
The goal of this paper is to understand the power of the Two-Sweep Greedy approach for computing
distributed defective colorings. We pursue this goal in two complementary directions.
    First, we show that this approach extends beyond ordinary defective coloring and can solve
a generalization of list defective coloring known as oriented list defective coloring [21]. We then
show that this more general form of list defective coloring, applied recursively, yields a new and
simple
   √ deterministic (∆ + 1)-coloring algorithm in the CONGEST model with round complexity
Õ( ∆) + O(log∗ n).
    Second, we investigate the intrinsic limitations of the same two-sweep paradigm. More concretely,
we ask for the smallest possible defect achievable when the number of output colors C is fixed.
We show that suitable choices of candidate palettes improve the known constants for many values √
of C, while also proving that no algorithm within this two-sweep framework can beat the 1/ C
relative-defect barrier asymptotically.

2.1    List Defective Coloring and Applications
We extend our Two-Sweep Algorithm to solve oriented list defective coloring (OLDC) instances. In
OLDC (formally defined below), the edges are oriented (possibly in both directions) and the defect
of a node is measured only with respect to its outgoing edges. As we will see, we need this more
general version of list defective coloring when using it as a building block for our new (∆ + 1)-coloring
algorithm formalized in Theorem 2.3.

Definition 2.1. Let G = (V, E) be a directed graph and C be a color space (i.e., a set of available
colors). For every node v ∈ V , we are given a list Lv ⊆ C and a defect function dv : Lv → N0 . For
the given lists and defect functions, a list defective coloring of G is a coloring of the nodes V such
that every node v is assigned a color x ∈ Lv such that v has at most dv (x) outneighbors of color x.

    In the above definition, N0 denotes the set of natural numbers including 0. If G is an undirected
graph and we replace every edge {u, v} of G by the two directed edges (u, v) and (v, u), then the
oriented list defective coloring gives a standard list defective coloring of G. When solving OLDC
problems in a distributed way, we assume that the communication graph G itself is an undirected

graph (i.e., communication can always happen in both directions) and the edge directions are given
as an edge orientation of G.
     Note that the Two-Sweep Algorithm directly applies to the oriented (list) defective coloring
problem. When applying the Two-Sweep Algorithm to an OLDC problem, in both sweeps, each
node only considers assignments of color sets (in the first sweep) or colors (in the second sweep) to
its outneighbors.

is, if v gets colored with color x, then at most dv (x) outneighbors of v are allowed to also be colored
with color x. Each node also comes with a set of color lists Sv ⊆ 2Lv . In this section, the set will be

    We note that throughout the algorithm, nodes do not consider their in-neighbors to guide their
decisions; in other words, nodes only look towards their outneighbors at all times. The algorithm
proceeds in two phases that we call Phase I and Phase II. In both phases, we iterate (sweep)
through the q initial colors, in ascending order in Phase I and descending order in Phase II. Let v
be a node with color c ∈ {1, . . . , q} from the initial q-coloring. Then, N< (v) is defined as the set
of outneighbors of v that have an initial color ∈ {1, . . . , c − 1} and similarly, N> (v) is the set of
outneighbors that have an initial color ∈ {c + 1, . . . , q}. Note that by the definition of a proper
coloring, there is no outneighbor that is also colored with color c and thus βv = |N< (v)| + |N> (v)|.

Let us briefly explain the intuition behind this definition. Our goal is to find a color that has a low
number of conflicts with the chosen colors of the outneighbors; hence, to decide on a good set of
colors Sv , we also want to minimize the number of conflicts with neighbors. Neighbors in N< (v)
have already chosen their sets and thus the number of conflicts with these neighbors is captured by
kv (x). On the other hand, neighbors in N> (v) have not yet chosen their sets and thus we can only
consider the worst case that all of them will choose a set containing colors with multiple conflicts.
On the other hand, the defect values dv (x) of our own colors help in minimizing the conflicts; hence,
they appear with a negative sign in the quality definition. The division by |S| is just a normalization
factor to make the quality of sets of different sizes comparable, so intuitively the quality measures
the average number of conflicts per color in S.
    In this generic Two-Sweep Algorithm we consider Sv to be part of the input. However, in our
implementations in Section 4 and Section 6, we give explicit constructions for Sv such that the set
with the best quality (i.e., the minimum value) is guaranteed to meet necessary requirements (e.g.,
Equation (5), as shown later).

A     Coloring Graphs of Bounded Neighborhood Independence
In this section, we present an application of our list defective coloring result Theorem 2.3 in graphs
of bounded neighborhood independence. The neighborhood independence θ of a graph G is the
maximum independent set size of any one-hop neighborhood of G, that is, the maximum independence
number of any of the induced subgraphs G[N (v)] for v ∈ V . Notable examples of graphs of bounded
neighborhood independence, i.e., where θ = O(1), are line graphs (of hypergraphs of bounded rank).
Another famous example is the family of claw-free graphs. In this work, we follow and extend the
algorithms of [22] and show that with only negligible changes in the round complexity, their results
for the LOCAL model are viable for the CONGEST model as well. We can actually keep all of the
recursive algorithms from [22] unchanged, but use Theorem 2.3 as the base case when the color space
C is already small. In particular, we show Theorem 2.4 as stated in the introduction.

Lemma B.5. Every set S ∈ S constructed from the first bucket has the same αS values and also the
αS values for sets from the second bucket are all equal.

Proof. The adversary’s objective is to make the final defect ρ as large as possible, i.e., it will decide
on the αS values in the linear program in a way that the value of z is as large as possible. Since in
both buckets we generate all possible sets of fixed length, each set in bucket one (respectively bucket
two) has the same number of conflicts as every other set in the same bucket. Hence, if the α value
of one of those sets would be smaller than the value of some other set from the same bucket, the
defect would become smaller to choose the set with the smaller value. Since the adversary wants to
maximize the defect, it will set all α values from the same bucket to be equal.
