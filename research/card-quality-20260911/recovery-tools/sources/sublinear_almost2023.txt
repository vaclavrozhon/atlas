1     Introduction
Graph spanners are sparse subgraphs that approximately preserve pairwise shortest-path distances.
Let G = (V, E) be an undirected unweighted graph on n vertices and let f : R+ → R+ be a
function. We say that a subgraph H ⊆ G is a spanner with stretch function f if for every pair
s, t ∈ V , distH (s, t) ≤ f (distG (s, t)). The research on spanners focuses on the optimal trade-offs
between the stretch function f and the sparsity (the number of edges) of the spanner H.
     One typical case is that we allow f (d) to be significantly greater than d, and such spanners are
known as multiplicative spanners. It was shown that for every integer k ≥ 1, there always exists a
subgraph H with O(n1+1/k ) edges and stretch function f (d) = (2k − 1)d [ADD+ 93]. Furthermore,
this sparsity bound is tight under the Girth Conjecture of Erdös [Erd63].
     Another typical case is that we restrict f to be very close to d. In particular, f (d) = d + O(1).
There has been a line of previous work studying the sparsity of spanners with such stretch functions.
When f (d) = d + 2, it was shown that graph G always has a spanner with O(n3/2 ) edges [ACIM99];
when f (d) = d + 4, a construction of spanner with Õ(n7/5 ) edges was proposed in [Che13]; when
f (d) = d + 6, spanners with O(n4/3 ) edges were known to exist by [BKMP10]. For the lower bound
side, in a recent breakthrough [AB17], it was proved that, for any constant ε > 0, there are graphs
such that any spanner with O(n4/3−ε ) edges has stretch nΩ(1) . Hence, we already have an almost
complete understanding of the spanner sparsity when f (d) = d + O(1).
     Besides the two typical cases mentioned above, much less is known when f lies in intermediate
regimes. Two notable regimes studied in previous works are the sublinear additive regime where
f (d) = d + o(d), and the additive regime where f (d) = d + o(n).
     As for sublinear additive spanners, Thorup and Zwick [TZ06, HP19] were the first to design
a nontrivial construction of sublinear additive spanners when f (d) = d + O(d1−1/k ) where k ≥ 2
is a constant integer, and the number of edges in the spanner is bounded by O(n1+1/k ). This

1.2     Technical overview
The basic tool of our algorithms is a clustering algorithm in [BW21]. Let G = (V, E) be the input
undirected unweighted graph. Roughly speaking, for any radius parameter R, we can decompose
the graph into a set B of balls that may share vertices, with the following properties.

   • (Radius) The radius of each ball in B is roughly R.

   • (Coverage) The union of all balls in B covers the whole graph G.

   • (Disjointness) The total size of the balls in B is linear in n.

   Next, we will describe how to utilize the above clustering to construct new sublinear additive
spanners and additive spanners, respectively.

1.2.1    Sublinear additive spanners
Our starting point is a spanner with stretch function f (d) = d + O(d1/2 ) and Õ(n8/7 ) edges, which
improves upon the previous sparsity bound of Õ(n20/17 ) in [Che13]. Consider any pair of vertices
s, t ∈ V , and let π be a shortest path between them of length D. We apply the clustering algorithm
from [BW21] with radius parameter R = D 1/2 to G, and obtain a set B of balls. Intuitively, by the
coverage property, and recalling that every ball in B has radius roughly R = D 1/2 , we can choose
a subset of O(D/R) = O(D 1/2 ) balls from B whose union contains the entire shortest path π. See
Figure 1 for an illustration.

    Therefore, it suffices to construct a spanner that faithfully preserves pairwise distances between
vertices in S. Consider now a pair s, t of vertices in S. We proceed similarly by first finding a
sequence of O(D 1/2 ) balls in B that covers the shortest path between s and t, and then computing
a sparse subgraph Hci ⊆ G[B(ci , ri )] in order to preserve the distance between wi and wi+1 to within
a constant additive error. Note that we would like that the graph Hci also approximately preserves,
for other pairs s′ , t′ ∈ S, the distance between their corresponding vertices wj′ , wj+1   ′  . The reason
that this is easier to achieve is because there are fewer pairs (wi , wi+1 ) assigned to the ball B(ci , ri )
while processing all pairs in S, as |S| itself is small. More formally, each ball B(ci , ri ) is associated
with a set Pci ⊆ V × V of demand pairs, and we want to find a spanner Hci ⊆ G[B(ci , ri )] that
only preserves distances between vertex pairs in Pci . The way we construct Pci is to enumerate all
pairs s, t ∈ S, find an s-t shortest path and a set of balls that cover it, and if we have used the
ball B(ci , ri ) in the covering, then add the corresponding pair (wi , wi+1 ) to Pci . In the end, we can
show that the size of each set Pci is at most |S| = Õ(n4/7 ).

pairs in Pci up to an additive error of 6. Then, the total size of all Hci is B(c,r)∈B |B(c, r)|·|Pc |1/4 =

1.2.2   Pairwise sublinear additive spanners
The only missing component towards a sublinear additive spanner with stretch f (d) = d+O(d1−1/k )
for general k ≥ 2 turns out to be a pairwise spanner with stretch d + O(d1−1/(k−1) ). As the previous
work on pairwise spanners [CGK13, Kav17] only considered stretch function f (d) = d + Õ(1), we

need to generalize their result for general k. Assume we are given an undirected unweighted graph
G = (V, E) on n vertices and a set P ⊆ V × V of pairs, and the goal is to find a spanner H ⊆ G
                         k+1
with at most Õ(n|P|1/2 ) edges, such that distH (s, t) ≤ f (distG (s, t)) for all (s, t) ∈ P. For the
purpose of this overview, we assume for simplicity that distG (s, t) = D for all (s, t) ∈ P.
    The construction of H is inductive on k ≥ 1. Assume we know how to construct such spanners
for k − 1. First, apply the clustering algorithm from [BW21] with radius R = D 1−1/k to graph G,
and obtain a set B of balls.

Uniform size. We start by considering a special case, where all balls in B have the same size
|B(c, r)| = L. By the disjointness property, the number of balls in B is approximately n/L. For each
pair (s, t) ∈ P, we compute a sequence of D 1/k balls and partition the shortest path connecting s, t,
in a similar way as illustrated in Figure 1. We wish to inductively build inside each ball G[B(ci , ri )]
a pairwise spanner with a better stretch d + O(d1−1/(k−1) ); if this is done, then the cumulative error
along the shortest path connecting s and t is bounded by D 1/k · R1−1/(k−1) = D 1−1/k .
    In order to apply the inductive hypothesis, we will construct, for each ball B(c, r) ∈ B, a set Pc
of demand pairs. But if we add, for all i, the pair (wi , wi+1 ) to Pci , then the sets |Pci | may become
too large (as large as |P|) to construct a spanner for. To circumvent this, we use the approach in
[Kav17]. Observe that, if we add each pair (wi , wi+1 ) to Pci , then not only the distance between s, t
is approximately preserved (in this case we call the pair (s, t) settled), but the distances between
all pairs of ball centers ci , cj are also approximately preserved. Now there are two cases. Let β be
a parameter to be determined later.

• Case 1. There are at least β · (l + 1) center pairs that were unsettled in H; recall that l + 1 refers
  to the number of clusters as in Figure 1.
  Then after adding each (wi , wi+1 ) as a demand pair to Pci , the total number of such center pairs
  would drop by β · (l + 1). In other words, each new demand pair (wi , wi+1 ) contributes β to the
  decrease of the number of unsettled center pairs on average.

• Case 2. There are fewer than β · (l + 1) center pairs that were unsettled in H.
  In this case, we show that there is always a “bridge” that helps settle the pair (s, t). Specifically,
  we can prove there are indices x ∈ [1, β], z ∈ [β + 1, l + 1 − β], y ∈ [l − β + 2, l + 1] such that center
  pairs (cx , cz ) and (cz , cy ) were already settled. In this case, adding demand pairs (wi , wi+1 ) to
  Pci only for i ∈ [1, β] ∪ [l − β + 2, l + 1] would be enough. See Figure 3 for an illustration.

   To summarize, for each pair (s, t) ∈ P, we either add at most 2β demand pairs in total, or add
a number of demand pairs such that the number of unsettled center pairs decreases by β per pair.

ball sizes to multiple ball sizes. In this general setting, every time we go down by one level on the
recursion tree and zoom into a smaller interval I, we will decrease the number of groups by one;
that is, there will be one more group whose pairs in this interval I are already purchased by our
algorithm. The recursion tree will have size 2O(1/ε) and will eventually incur an additional factor
2O(k/ε) nO(kε) in the sparsity.

6.1   A subquadratic time algorithm for Õ(n3/7+ε ) additive spanner
In this subsection, we prove the following theorem, which shows that an additive spanner with the
current best error (as in [BW21]) can be computed in subquadratic time.

Theorem 6.1. There is an algorithm, that, given any undirected unweighted graph on  n vertices
and m edges, and any parameter ε > 0, computes a spanner on O 2    O(1/ε) · n log n edges with
Õ(n3/7+ε ) additive stretch, in time Õ m + 2O(1/ε) · n13/7 .

2O(1/ε) n by replacing Lemma 2.2 with the original Lemma 13 from [BW21].

    We start with the following lemma for a preliminary sparsification of the input graph.

Lemma 6.3. There is an algorithm, that given any graph G and parameter 1 < d < n, computes
in Õ(m) time an +Õ(n/d) spanner G′ of G with |E(G′ )| ≤ O(nd) edges.

Proof. Graph G′ is simply the union of (i) for each vertex v ∈ V (G) with degG (v) ≤ ⌈d⌉, all incident
edges of v; and (ii) an O(log n)-multiplicative spanner of G with O(n) edges; such a multiplicative
spanner can be computed in Õ(m) time as shown in [BS07]. Clearly, graph G′ can be computed in
Õ(m) time.
   Consider now any pair s, t ∈ V (G) and let π be an s-t shortest path in G. It is easy to observe
that at most O(n/d) vertices in π have degree more than d, so the number of edges in E(π) that

                                                      27
is incident to any degree ≤ d vertex is at most O(n/d). As we have included in G′ an O(log n)-
multiplicative spanner of G, the distance in G′ between the pair of endpoints of every such edge is
at most O(log n). Therefore, distG′ (s, t) ≤ distG (s, t) + Õ(n/d).

   We now proceed to describe our algorithm for Lemma 6.10. Similar to Section 5, we assume
that the (unit) edge weights are slightly perturbed so that for every pair s, t there is a unique

A     Proof of Lemma 2.2
Throughout, we use the parameter β = nε .
    The algorithm iteratively builds the collection B. Initially, B = ∅. The algorithm continues to
be executed as long as there exists a vertex that is not covered by the collection B. We now describe
an iteration. First, we pick an arbitrary vertex c that is not covered by the current collection B,
and add a new ball B(c, r) to B centered at c. Its radius r is determined by the following process:

 (1) Start with r = R.

 (2) Perform breadth-first search from c in G to compute the ball B(c, 4r).

 (3) If |B(c, 4r)| ≤ β · |B(c, r/2)| and vol(B(c, 4r)) ≤ β · vol(B(c, r/2)), then add the ball B(c, r) to
     B, and terminate the iteration. Otherwise, update r ← 4r and repeat Steps (2) and (3).

    We now proceed to analyze the algorithm. First, it is easy to see that the radius of every ball
in B at the end of the algorithm is at least R, as the process of determining the radius of each new
ball start with r = R and only increases r afterwards. Second, from the algorithm, when a new ball
is added to B, its radius r is determined by an iterative process, where in each round, r is increased
by a factor of 4 whenever |B(c, 4r)| > β · |B(c, r/2)| or vol(B(c, 4r)) > β · |B(c, r/2)|. As |B(c, 4r)|
and vol(B(c, 4r)) arebounded  by n and m respectively, the number of times that the radius r is
increased is at most logβ n + logβ m < 5/ε. Therefore, in the end, r ≤ R · 45/ε = R · 210/ε .
    We next prove the following observation.

Observation A.1. At the end of the algorithm, for every vertex v ∈ V , there are at most 5/ε balls
B(c, r) in B, such that distG (c, v) ≤ r/2.
