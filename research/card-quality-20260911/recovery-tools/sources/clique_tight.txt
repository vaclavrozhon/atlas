                                                                                      Abstract
                                             Much progress has recently been made in understanding the complexity landscape of sub-
                                         graph finding problems in the CONGEST model of distributed computing. However, so far, very
                                         few tight bounds are known in this area. For triangle (i.e., 3-clique) listing, an optimal Õ(n1/3 )-
                                         round distributed algorithm has been constructed by Chang et al. [SODA 2019, PODC 2019].
                                         Recent works of Eden et al. [DISC 2019] and of Censor-Hillel et al. [PODC 2020] have shown
                                         sublinear algorithms for Kp -listing, for each p ≥ 4, but still leaving a significant gap between
                                         the upper bounds and the known lower bounds of the problem.
                                             In this paper, we completely close this gap. We show that for each p ≥ 4, there is an
                                         Õ(n1−2/p )-round distributed algorithm that lists all p-cliques Kp in the communication network.
                                         Our algorithm is optimal up to a polylogarithmic factor, due to the Ω̃(n1−2/p )-round lower bound
                                         of Fischer et al. [SPAA 2018], which holds even in the CONGESTED CLIQUE model. Together
                                         with the triangle-listing algorithm by Chang et al. [SODA 2019, PODC 2019], our result thus
                                         shows that the round complexity of Kp -listing, for all p, is the same in both the CONGEST and
                                         CONGESTED CLIQUE models, at Θ̃(n1−2/p ) rounds.
                                             For p = 4, our result additionally matches the Ω̃(n1/2 ) lower bound for K4 -detection by
                                         Czumaj and Konrad [DISC 2018], implying that the round complexities for detection and listing
                                         of K4 are equivalent in the CONGEST model.
1     Introduction
Subgraph detection and listing are fundamental graph problems that have been extensively studied
in various computational models [2, 3, 11, 17, 23, 25]. In this paper, we focus on the CONGEST
model of distributed computing, where the communication network is identical to the n-node input
graph G = (V, E). In this model, each node v ∈ V represents a computing device, and each edge
e ∈ E represents a communication link. Each node v ∈ V has an O(log n)-bit unique identifier
ID(v). The communication proceeds in synchronous rounds. In each round, each node v can send
an O(log n)-bit message along each edge e incident to v.
    Given a fixed graph H, the H-detection problem requires that at least one node in the network
detects a copy of H if the underlying network G contains H as a subgraph, and the H-listing
problem requires that each subgraph H of G is detected by some node in the network.

1.1   Prior Work on Distributed Clique Listing
The Kp -listing problem, for all p, can be solved trivially in Õ(∆) rounds by having each node v
broadcast the list {ID(u) | u ∈ N (v)} to all its neighbors N (v), where ∆ < n is the maximum
degree of the graph. The first breakthrough in this area is by Izumi and Le Gall [19], who showed
that K3 -detection and listing can be solved in Õ(n2/3 ) rounds and Õ(n3/4 ) rounds, respectively.
     Later, Chang et al. [6] and Chang and Saranurak [7] brought the round complexity down to
Õ(n1/3 ), matching the Ω̃(n1/3 ) lower bound [19, 24] by a polylogarithmic factor. The main idea
underlying the approach of [6, 7] is expander decompositions. An expander decomposition removes
-fraction of the edges so that the remaining connected components have conductance at least φ.
It was shown in [6, 7] that an expander decomposition with parameters  = 1/ polylog(n) and
φ = 1/ polylog(n) can be constructed in O(n0.001 ) rounds.
     Once an expander decomposition is constructed, we can apply expander routing [14, 15] to each
high-conductance cluster C in the expander decomposition. Specifically, after O(n0.001 ) rounds
of pre-processing, within poly(φ−1 , log n) rounds we can let each v ∈ C communicate with any
arbitrary degC (v) nodes in C, not just the local neighbors of v [7], where degC (v) is the number of
neighbors of v in C.
     Using expander routing, Kp -listing can be solved in Õ(n1−2/p ) rounds on graphs with conduc-
tance φ = 1/ polylog(n) [6]. Based on this result, the K3 -listing algorithm of [14, 15] works as
follows. Construct an expander decomposition to partition the nodes into high-conductance clus-
ters. For each cluster C, use expander routing to list all K3 involving at least one edge in C, in
parallel, in Õ(n1/3 ) rounds. Then recurse on the subgraph induced by the remaining inter-cluster
edges.
     Things become complicated when p ≥ 4, as Kp can involve edges in more than one cluster in
this case. The first sublinear Kp -listing algorithms for p = 4 and p = 5 were given by Eden et
al. [10]. To deal with the cross-cluster clique instances, they classify the nodes outside a cluster C
into heavy nodes and light nodes based on the number of neighbors in C. Each heavy node v has
sufficiently many neighbors in C so that v has enough bandwidth to send its entire list of neighbors
to C efficiently. For each light node v, it only needs to send its list of neighbors restricting to
those in C, and this can be done efficiently since a light node only has a small number of neighbors
in C. Choosing the threshold of the classification properly, this information gathering can be done
in sublinear rounds. After this step, each cluster C contains all the edges that can potentially form
a clique Kp with existing edges in C. Finally, they apply the expander routing to each cluster C
to solve the Kp -listing problem. Using this approach, they showed that K4 and K5 can be listed in
Õ(n5/6 ) and Õ(n21/22 ) rounds, respectively.

    Recently, Censor-Hillel et al. [4] showed that Kp -listing can be solved in sublinear rounds for
all p. One major shortcoming of the approach of [10] is that the number of edges sent to a cluster C
can be significantly larger than the number of edges in C. As the total bandwidth in expander
routing depends on the number of edges in C, this makes the listing algorithm inefficient. To
overcome this issue, Censor-Hillel et al. [4] proposed the following arboricity decreasing framework,
which is based on a variant of the expander decomposition considered in [6] that allows an additional
small arboricity part Es .
    The expander decomposition of [6] partitions the edge set E into three parts Em , Es , and Er .
The set Em represents the edges inside a high-conductance cluster. The set Es induces a subgraph
of arboricity at most nδ , where 0 < δ < 1 is a given parameter. The set Er is the remaining edges,
and it satisfies |Er | < |E|/6. In this decomposition, each cluster C of Em not only has conductance
1/ polylog(n) but also each node v in C has Ω(nδ ) neighbors in C. Such a decomposition can be
constructed in Õ(n1−δ ) rounds [6].
    The idea of [4] is to first recurse on Er . After Er is empty, recurse on Es with a slightly smaller
parameter δ, and so the arboricity of the graph is gradually decreasing during the process. This
approach ensures that during the process, the minimum degree in a cluster under consideration is
within a small factor to the overall arboricity of the graph. They showed that Kp -listing can be
solved in Õ(n2/3 ) rounds for p = 4 and Õ(np/(p+2) ) rounds for p ≥ 5.
    This still leaves a significant gap between the upper bounds of [4] and the Ω̃(n1−2/p )-round lower
bound of Fischer et al. [13].

1.2   New Result
In this paper, we prove the following theorem, which completely closes this gap.

Theorem 1.1. For each p ≥ 4, the Kp -listing problem can be solved in Õ(n1−2/p ) rounds with high
probability in the CONGEST model.

    More precisely, our result matches the Ω̃(n1−2/p ) lower bound for Kp -listing of Fischer et al. [13]
up to a polylogarithmic factor, and it also matches the Ω̃(n1/2 ) lower bound for Kp -detection of
Czumaj and Konrad [8] for the case of p = 4.
    Prior to this work, there were only two known non-trivial tight bounds in the area of distributed
subgraph listing: Θ̃(n1/3 ) for triangles K3 [7] and Θ̃(n) for 4-cycles C4 [10].
    The CONGESTED CLIQUE model is a variant of CONGEST that allows all-to-all communica-
tion in each round. The lower bound of [13] also holds in the CONGESTED CLIQUE model, and
so our result shows that the round complexity of Kp -listing is the same in both CONGEST and
CONGESTED CLIQUE up to a polylogarithmic factor, and this implies that allowing distant nodes
to communicate directly does not allow us to list cliques much faster. This statement is not true
for many other subgraphs. For C4 , detection and listing can be solved in O(1) and Õ(n1/2 ) rounds
in CONGESTED CLIQUE, respectively [5], but these problems have much higher lower bounds in
CONGEST: Ω̃(n1/2 ) for detection [9, 22] and Ω̃(n) for listing [10].

1.3   Technical Overview
As discussed earlier, there are two main challenges in dealing with cross-cluster cliques for the case
of p ≥ 4. The first challenge is that each cluster C needs to efficiently list all Kp with at least one
edge inside C. The main difficulty here is that the number of relevant edges outside of C that can
form a Kp with existing edges in C can be much higher than the number of edges in C. In other
words, the problem size for subgraph listing can be much higher than the number of edges that can


                                                   2
be used in communication. The second challenge is that each cluster C needs to efficiently gather
all the needed information from outside of C into C. Specifically, we need to let C learn each edge
outside of C that can potentially form a Kp instance with edges in C.

Optimal sparsity-aware listing. Our main technical ingredient to deal with the above first
challenge is an optimal sparsity-aware listing algorithm (Theorem 3.2 in Section 3) We show that
the task of listing all instances of Kp with at least one edge in C can still be solved optimally in
Õ(n1−2/p ) rounds, as long as the average degree in C = (VC , EC ) satisfies some mild requirements.
This result works even in the case the number of edges outside of C is much higher than the number
of edges in C. For comparison, the previous attempts in coping with this challenge mostly only
focus on limiting the number of edges outside of C to consider [4, 10].
    Before explaining our algorithm, let us review the Kp -listing algorithm on a high-conductance
graph G = (V, E) in [6]. Partition the node set V into n1/p parts, so that the number of p-tuples
of parts is n. Associate each node v ∈ V with O(deg(v) · |V |/|E|) p-tuples, and each node v is
responsible for listing all Kp corresponding to the p-tuples assigned to v. A simple calculation
shows that if the partition is done randomly, then each node needs to gather deg(v) · O(n1−2/p )
edges in expectation to fulfill its clique listing task. A more complicated calculation shows that the
actual number of edges is concentrated around its expectation, and so we can use the expander
routing algorithm of [14, 15] to solve the Kp -listing problem in Õ(n1−2/p ) rounds. Note that this
algorithm does not give us the optimal round complexity in our setting, as the number of edges
under consideration for Kp -listing can be much higher than the number of edges that can be used
in communication.
    The new idea in this paper is to exploit the varying sparsity of different edge sets. Instead of
partitioning the nodes into n1/p parts with roughly equal size, we allow different parameters for
the number of parts for VC and V \ VC in the random partition. We show that if the average
degree |EC |/|VC | of C is sufficiently high, and if each node v ∈ VC has 1/ polylog(n) fraction of its
neighbors in C, then we can still achieve the optimal round complexity Õ(n1−2/p ).
    For this to work, we need to show good bounds on the number of edges that we can have between
any two parts in the random partition. To this end, we prove a partition lemma (Lemma 3.1 in
Section 3), which generalizes [6, Lemma 4.2] to multiple edge sets.

Efficient transmission of edges across clusters. For the above second challenge, in this paper
we adapt an approach similar to the classification of nodes into heavy ones and light ones in [10].
Considering a cluster C, we want to gather all the edges that can potentially form a Kp with edges
in C. Define S ∗ as the set of nodes v ∈ V \ VC such that degV \VC (v) = Ω(n1−2/p · degC (v)), i.e.,
the number of neighbors of v outside C is at least Ω(n1−2/p ) times the number of neighbors of v
inside C. We call the nodes in S ∗ the light nodes. Observe that each heavy node v ∈ (V \ VC ) \ S ∗
can send all its incident edges to C in O(n1−2/p ) rounds, due to its high number of neighbors in C.
    We focus on the light nodes in the subsequent discussion. Define S as the subset of VC such
that v ∈ S if v has Ω(n1−2/p ) neighbors in S ∗ . Note that each v ∈ VC \ S can learn all the relevant
edges incident to the light nodes that can potentially form a Kp with v. Therefore, the only bad
edges that we cannot deal with are the edges contained in S. We will show that it is possible to
assume that each cluster has at least Ω(n1−2/p ) nodes, and so there are at most O(n2/p ) clusters. A
calculation reveals that whenever p ≥ 5, the set of bad edges over all clusters constitute at most a
constant fraction of E. By deferring dealing with these bad edges to subsequent iterations, we are
done listing all instances of Kp after O(log n) iterations. Section 4 contains the above proof, thus
we obtain Theorem 1.1 for p ≥ 5.

    A different strategy is needed to deal with K4 , as in this case we cannot obtain a good bound
on the number of bad edges. We construct an expander decomposition recursively on the subgraph
induced by the inter-cluster edges to cover all edges by high-conductance clusters. Now we only
need to consider K4 = {v1 , v2 , v3 , v4 } instances crossing a cluster C at the top-level expander
decomposition and some other other cluster C ∗ in the sense that {v1 , v2 } ∈ EC and {v3 , v4 } ∈ EC ∗ .
We go over all possible pairs of C and C ∗ in parallel to let C learn the edges in C ∗ that can potentially
form a K4 with edges in C, by applying our above approach, replacing V \ VC by VC ∗ \ VC .
    The advantage of this new strategy is that it allows us to deal with the bad edges as follows. It
is possible to show that the bad edges in C can be sent to C ∗ efficiently. Moreover, the subgraph
induced by the bad edges is sufficiently sparse that we can apply our sparsity-aware listing algorithm
to C ∗ to list all the cross-cluster K4 associated with the bad edges in Õ(n1−2/p ) rounds. Section 5
contains the above proof, thus we obtain Theorem 1.1 for p = 4.

1.4    Additional Related Work
While our work solves Kp -listing for all p ≥ 4 in optimal round complexity due to the lower bound
of Fischer et al. [13], for the Kp -detection problem, the only lower bound known is due to Czumaj
and Konrad [8], who showed that Ω̃(n1/2 ) rounds are needed for Kp detection for all 4 ≤ p ≤ n1/2
and that Ω̃(n/p) rounds are needed for Kp detection for all p ≥ n1/2 .
     For cycles, Drucker et al. [9] showed that for fixed p ≥ 4, Cp -detection requires Ω(ex(n, Cp )/n))
rounds, where ex(n, H) is the Turán number that counts the maximum number of edges that an
n-node graph can have without containing a subgraph isomorphic to H. Therefore, we have a
lower bound of Ω̃(n) for detecting Cp when p is odd, and we have a lower bound of Ω̃(n1/2 ) for
the case p = 4. Korhonen and Rybicki [22] extended this result to make the Ω̃(n1/2 ) lower bound
apply for all even p. They also showed that Cp -detection can be solved in Õ(n) rounds for any
constant p, implying that for constant odd values p the complexity for Cp -detection is Θ̃(n). For
even-length cycles, Fischer et al. [13] showed that C2p -detection can be solved in O(n1−1/(p(p−1)) )
                                                                     2
rounds. Eden et al. [10] later improved this result to Õ(n1−2/(p −p+2) ) rounds for odd p ≥ 3, and
                    2
at most Õ(n1−2/(p −2p+4) ) rounds for even p ≥ 4. Using expander decompositions, Eden et al. [10]
demonstrated a barrier to proving lower bounds for even-length cycle detection. There is a constant
δ ∈ (0, 1/2) such that any Ω(n(1/2)+δ ) lower bound on C2p -detection would imply a new circuit
lower bound.
     Subgraph detection beyond cliques and cycles were also considered in the literature [12,13,16,22].
Fischer et al. [13] constructed a family of graphs Hp with p nodes such that Hp -listing requires
Ω(n2−1/p /p) rounds. Later, Eden et al. [10] showed that for any p-node graph H, the H-detection
problem can be solved in n2−Ω(1/p) rounds, almost matching the lower bound of Fischer et al. [13].
     Variants of subgraph finding problems requiring subgraphs to be reported by its constituent
nodes were considered in [1, 13, 18, 19]. This additional requirement changes the nature of the
problem drastically. For example, the local triangle listing problem, which requires each K3 to
be reported by one of its three constituent nodes, requires Ω̃(n) rounds [19], while the standard
triangle listing problem has round complexity Θ̃(n1/3 ). For the simpler problem that asks each
node to decide whether it belongs to a triangle, any one-round deterministic algorithm requires
messages of size Ω(∆ log n) [1], matching the trivial upper bound. For the randomized setting,
there is an Ω(∆) lower bound [13] for the same problem. From the upper bound side, Huang et
al. [18] showed that the local triangle listing problem can be solved in O(∆/ log n+log log ∆) rounds
with high probability, matching the Ω(∆/ log n) lower bound of Izumi and Le Gall [19] whenever
∆ > log n log log log n.
     Quantum algorithms for distributed triangle detection have been proposed recently by Izumi


                                                    4
et al. [20], where they showed that triangle detection can be solved in Õ(n1/4 ) rounds in the quantum
version of CONGEST. This gives another example of a quantum algorithm beating the best known
classical algorithms in distributed computing, as the current best known upper bound for distributed
triangle detection in the classical setting is Õ(n1/3 ) [7].

V1 ∪ V2 ∪ · · · ∪ Vk satisfying the following conditions.
    • For each cluster Vi , we have Φ(G{Vi }) ≥ φ.

Theorem 2.1 (Expander decomposition [7]). An (, φ)-expander decomposition with  = 1/ polylog(n)
and φ = 1/ polylog(n) can be constructed in O(n0.001 ) rounds with high probability.
    Note that we have the conductance guarantee not only for G[C] but also for G{C}, for each
cluster C = (VC , EC ) in the expander decomposition. In particular, each v ∈ VC with |VC | > 1
must have at least an 1/ polylog(n) fraction of its neighbors in C, since otherwise G{C} cannot
have mixing time polylog(n).
Theorem 2.2 (Expander routing [7, 14]). Suppose τmix (G) = polylog(n). There is an O(n0.001 )-
round algorithm that pre-processes the graph such that for any subsequent routing task where each
node v is a source and a destination of at most L · deg(v) messages of O(log n) bits, all messages
can be delivered in L · polylog(n) rounds with high probability.
    To summarize, combining Theorem 2.1 and Theorem 2.2, in O(n0.001 ) rounds we can partition
the node set V into clusters with small mixing time polylog(n) and so the above routing task can
be solved efficiently. Furthermore, for a node v ∈ VC for any cluster C = (VC , EC ) with |VC | > 1, it
holds that degC (v) ≥ deg(v)/ polylog(n). Note that for the trivial case of |VC | = 1, we have EC = ∅,
and so there is no Kp with edges in C. Therefore, in subsequent discussion, we only consider the
clusters with more than one node.

to optimally list all copies of Kp , for a given p ≥ 4, with at least one edge in the subgraph, and
potentially other edges outside of it. In order to show this algorithm, we begin by presenting a
partitioning lemma, and then proceed to showing a theorem which performs sparsity aware listing.

4     Optimal Kp -listing Algorithm for p > 4
We show here how to list all instances of Kp , for p > 4.
    We start with a simple procedure, in which each node of small degree lists all cliques that it is
a part of by an exhaustive search approach. Formally, each node v with deg(v) ≤ 2n1/2 sends its
neighborhood N (v) to all of its neighbors in N (v). Each neighbor sends an ack about each neighbor,
and so v learns about all edges in N (v) × N (v), thereby v lists all Kp instances involving it. Thus
we remove from the graph the node v and all edges touching v. This clearly takes at most O(n1/2 )
rounds, according to the degree condition for v.
    This procedure does not give us any promise on the degrees given by the remaining edges because
by removing edges we could now have additional low-degree nodes. However, the property that this
guarantees is that this handles many nodes in case the average degree in the graph was initially not
too large. Denote by µ the average degree of the graph.

µn/2γ 0 = (2/γ 0 )µn/4 ≤ (2/γ 0 )|E|/2 = (1/γ 0 )|E|.
    To summarize, we obtain that |Elow | ≤ (1/γ)|E| + (1/γ 0 )|E| = (1/γ + 1/γ 0 )|E|, as claimed.

    We show that the conditions of the theorem hold for any cluster C = (VC , EC ) with |VC | ≥
βn1−2/p which is not a low-average cluster.
    First, by Property 2 above, we have that the mixing time of C is O(polylog(n)). Furthermore,
by Property 3, we have that for every u ∈ VC it holds that deg(u) is at most Õ(degC (u)), which
implies that degĒ (u) is also bounded by Õ(degC (u)), where Ē is a subset of E(VC , V \ VC ). In
addition, if we consider the set of edges E 0 ⊆ E(V \VC , V \VC ) that are distributed among the nodes
of C, then indeed each node u ∈ VC holds no more than O(n1−2/p · degC (u)) of those edges. The
reason is that each edge of E 0 that reaches u, reaches it through one of its edges in E(VC , V \ VC ).
There are at most Õ(degC (u)) edges in the latter, and only O(n1−2/p ) rounds, which implies the
required bound on the amount of information that they convey to u.
    Finally, we note that the bounds required by Equation 1 hold for C which is not a low-average
cluster, by definition.
    Since all required conditions hold, we now execute the algorithm provided by Theorem 3.2 on
each cluster C with |VC | ≥ βn1−2/p which is not a low-average cluster. We then remove all edges
(VC ×SVC ) \ (SC × SC ) in each such cluster C and continue to the next iteration with all edges in
Er ∪ C such that |VC |≥βn1−2/p (SC × SC ) ∪ Elow .
    By Property 1 above, Claim 4.3, and Claim 4.4, there are no more than (1/ polylog(n) + 4/β +
1/γ + 1/γ 0 )|E| remaining edges if the average degree µ of the graph is at least µ ≥ n1/2 . Choosing

                                                   14
β = 32, γ = 8, and γ 0 = 8, gives that there are at most 4(1/8)|E| = |E|/2 remaining edges.
    In case the average degree µ of the graph is bounded by µ < n1/2 , the initial exhaustive search
procedure for nodes of degree at most 2n1/2 removes at least half of the nodes by Claim 4.1.
    This implies that we complete within a logarithmic number of iteration, which proves that within
Õ(n1−2/p ) rounds we list all instances of Kp , for p > 4.
