                                                                                          Abstract
                                                                                                                                     √
                                                    In this article we prove the subrank of a generic tensor in Cn,n,n to be Q(n) = ⌊ 3n − 2⌋
                                                 by providing a lower bound to the known upper bound. More generally, we find the generic
                                                 subrank of tensors of all orders and dimensions. This answers two open questions posed in
                                                 [DMZ24]. Finally, we compute dimensions of varieties of tensors of subrank at least r.

                                           1     Introduction
                                           Geometry of tensors is a subject of great importance in mathematics, physics and computer science
                                           with numerous applications in complexity theory (fast matrix multiplication, P vs NP problem,
                                           etc.) [Lan12, Lan17], quantum information theory [Lan24] and other areas of science ranging from
                                           signal processing to chemistry [KB09].
                                               The subrank of a tensor is an important notion in algebraic complexity theory introduced by
                                           Strassen in [Str87] to analyse the complexity of matrix multiplication. As a dual notion to tensor
                                           rank, it serves as one of the crucial invariants of tensors that has been extensively researched
                                           over the years. Recently, numerous other invariants of tensors, such as the slice rank [Tao16], the
                                           analytic rank [GW11], and the geometric rank [KZ20], have been introduced and investigated. It
                                           is known that the subrank provides a lower bound for all invariants mentioned above.
                                               In this work we are interested in generic values of the subrank, that is, the subrank of ”almost
                                           all” tensors in a given tensor space. More precisely, one can show [DMZ24, Proposition 2.1] that
                                           for any tensor space there is a Zariski open subset of tensors where subrank is constant. We call
                                           this number the generic subrank and denote the subrank of a generic tensor T ∈ K n1 ,n2 ,n3 by
                                           Q(n1 , n2 , n3 ) with a shorthand Q(n) = Q(n, n, n).
                                               Strassen [Str91] and Bürgisser [Bü90] found the upper bound for the generic subrank Q(n) ≤
                                           n2/3+o(1) but exact asymptotic values have been unknown
                                                                                                 √        for a long time. Only recently it has
                                           been shown in [DMZ24] that, in fact, Q(n) = Θ( n). Interestingly, the generic value of ten-
                                           sor parameters introduced above is the maximal value n, hence the subrank is much lower than
                                           aforementioned ranks for a generic tensor.
                                               We note that determining precise generic values for tensor invariants is a difficult problem. For
                                           instance, generic values for a rank are unknown in general (see [Str83, Fri12] and Subsection 5.1).
                                           We highlight one example where generic values are known. Namely, Alexander and Hirschowitz
                                           (see [AH95] and [Lan17, Chapter 5.4 and      Chapter
                                                                                     n+d−1   15]) showed that a generic symmetric d-tensor
                                                                                      (    )
                                           in K n,...,n has generic symmetric rank       n
                                                                                         n      apart from a known list of exception where the
                                           values are also known.
                                              In this paper we find precise values of the generic subrank of tensors of any order and shape,
                                           thus providing a complete answer to the problem of determining values of the generic subrank.

    Later, when we decribe the algorithm to find such a monomial, we will not use this formal

Lemma 2.8. If there is a unique row monomial of a k × ℓ matrix M0 over an infinite field, then
M0 has generically full row rank, that is rank k.

Proof. For each i, we take every ai in Mi−1 . They are in different rows and columns and there is
k of them, so they form a monomial in a certain k × k minor of M0 . By construction, there is no
other way to get this monomial in any minor. Thus, M0 has a k × k minor which is non-zero as a
polynomial, which in an infinite field means that it is non-zero on an open set of values of ai .

Definition 2.10. There is a natural Z/rZ-action on the set Pr , which we identify with rows of
M , given by a · (i, j, k) = (i + a, j + a, k + a) mod r. For t = 1, 2, 3 we say that a set B of b
orbits under this action is a t-block of size b if for any two orbits O1 , O2 ∈ B and some (or,
equivalently, any) p1 ∈ O1 there exists p2 ∈ O2 such that p1 and p2 differ only in the t-th place,
e.g. p1 = (i1 , j, k) and p2 = (i2 , j, k) for t = 1. Note that 0 ≤ b ≤ r − 2.

   We also point out this simple property which will be useful later.
Lemma 2.11. If t1 ̸= t2 , then a t1 -block and a t2 -block share at most one orbit.
Proof. Note that there is a unique t ̸= t1 , t2 . From each orbit we can pick a unique representative
which has a 1 on the t-th place. Assume the two blocks share at least one orbit, whose representative
is p. Then all other representatives of (orbits of) the t1 -block can be obtained by changing the
t1 -th number of p, and similarly, other representatives of the t2 -block can be obtained by changing
the t2 -th number in p. Changing the t1 -th and t2 -th number clearly gives different results, so the
blocks share no other orbit.
   In our algorithm, we will always cross out whole orbits. This leads us to a notion of a crossed
orbit.

Definition 2.12. Assume that elements (rows) of every orbit are either all crossed or all uncrossed.

with respect to inclusion.

Theorem 2.13. Let t ∈ {1, 2, 3}. Consider a maximal uncrossed t-block of size b and let B be

precisely all rows in B and all columns in C so that in each step when a variable ã is crossed out
then all its occurrences are crossed out as well.
   Note that |B| = |C|, which is clearly necessary. Remember that whenever we cross out a
variable, we must cross out all its occurrences. Let us first state a lemma.
Lemma 2.14. Let ã be a variable in the matrix. Assume there is a row in B containing ã and
there is a column in C containing ã. Then all occurrences of ã in the matrix lie in the rows of B
and in the columns of C.
Proof. We can assume t = 1 since other cases are analogous. Note that an element a1,s
                                                                                  j,k lies precisely
in the rows indexed by (m, j, k) and the columns indexed by (1, m, s) with m ∈ [r] \ {j, k}. If C
contains one of such columns then it contains all of them. On the other hand, if one of the rows
is in B, then, since B is a maximal uncrossed 1-block, all rows obtained by changing m are either
in an orbit of the block, or in a crossed orbit.
   The proof of Theorem 2.13 will allow us to cross out variables in an arbitrary order.

Proof of Theorem 2.13. We pick any variable that lies in an uncrossed row of B and an uncrossed
column of C and cross out all rows and columns where it occurs. By Lemma 2.14, we will cross
out only allowed rows and columns. Then we pick another variable with the same properties and
repeat the process. To complete the proof we show that as long as there is an uncrossed column in
C (or, equivalently, an uncrossed row in B since |B| = |C|), there is always an uncrossed element
in this column, which we can pick.
    We prove it for t = 1 since other cases are analogous. Assume, for contradiction, that a column
(1, m, s) ∈ C is uncrossed but all non-zero entries of the column lying in rows of B are crossed
(note that this can happen only if their corresponding rows are crossed). These entries are a1,s  j,k in
the row (m, j, k) for all j, k such that (m, j, k) ∈ B. In every orbit in B, there is exactly one index
triple with the first index equal to m, so there is b of them in B. If all these rows are crossed then
each of them contains an element that has been crossed out. But note that every such element lies
in a column (1, m, s′ ) for some s′ ∈ S. Now, since no two elements in one column can be crossed
out, we see that b columns of the type (1, m, s′ ) in C were crossed out. Since there are precisely
b columns of this form in C, the column (1, m, s) must have been crossed out as well, which is a
contradiction.

many times to make M a square matrix. Then by Theorem 3.6 it has full row rank and thus full
rank. Then since it is a square matrix, all the columns of the new matrix are linearly independent,

5      Further research directions
In this section we highlight several possible direction for further research.

5.1     Generic rank
While the asymptotic growth of a generic rank and its values for tensors of certain shapes (e.g., in
K n,n,n ) are known, exact values are still unknown in general [Fri12]. In the spirit of this paper,
one can rephrase the question of finding exact values of a generic rank to a question about the
generic rank of a matrix by taking the differential of the map ψr :

5.2     Equations of the varieties Cr
Another interesting problem to consider concerns the description of the ideal I(Cr ). Note that it
is a difficult problem as, for instance, Cr ⊂ K r,r,r = {T ∈ K r,r,r |R(T ) ≤ r} which is the r-th
secant variety of the Segre embedding. Describing the equations of secants of Segre varieties is a
major open problem as these varieties are loci of tensors of border rank at most r (see [LM06] and
[Lan12, Chapter 7] for more information).
    We note that in general there are still some similarities with the case of secants of Segre varieties
since Cr ⊂ K n,n,n is invariant under the action of GLn × GLn × GLn so we can study I(Cr ) with
the tools from representation theory.
