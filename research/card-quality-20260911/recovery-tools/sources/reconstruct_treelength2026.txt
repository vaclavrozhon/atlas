                                                                                            Abstract
                                                      We consider the following graph reconstruction problem: given an unweighted connected
                                                  graph G = (V, E) with visible vertex set V and an oracle which takes two vertices u, v ∈ V and
                                                  returns the shortest path distance between u and v, how many queries are needed to reconstruct
                                                  E?
                                                      Specifically, we consider bounded degree ∆ and bounded treelength tl connected graphs and
                                                  show that reconstruction can be done in O∆,tl (n log n) queries with a deterministic algorithm.
                                                  This result improves over the best known algorithm (deterministic or randomized) for this graph
                                                  class by a log n factor and matches the known lower bound for the class of graphs with bounded
                                                  chordality, which is a subclass of bounded treelength graphs.


                                         1       Introduction
                                         In the graph reconstruction problem, only the vertex set V of a hidden graph G = (V, E) is visible,
                                         and the goal is to reconstruct the edge set E by querying an oracle. A graph reconstruction
                                         algorithm aims to discover the edge set with as few adaptively chosen queries as possible. The
                                         reconstruction task is considered complete once there is a unique graph consistent with all answers
                                         to the queries. Several query models have been studied for graph reconstruction, including edge
                                         existence queries, edge counting, effective resistance queries, and shortest path queries [RS07, AC04,
                                         HMMT18, ABK+ 04, AA05, BBNW26].
                                             In the Shortest Path (SP) distance query model, we have access to a distance oracle: for any
                                         two vertices u, v ∈ V , a query returns the length of the shortest path between u and v in G and
                                         returns ∞ if no such path exists.
                                             The study of network reconstruction using shortest path queries is motivated by applications
                                         such as Internet topology reconstruction and evolutionary tree reconstruction [Hei89, WSSB77,
                                         BEE+ 05, DAHB+ 06, ACKM09].
                                             Any (unweighted) graph can trivially be reconstructed using n2 SP queries, simply by querying

                                         every pair of vertices to check whether they are adjacent. Unfortunately, this upper bound is tight
                                         even for trees, once we allow unbounded degree [RS07].

    Moreover, the bound is tight if one allows disconnected graphs–reconstructing a graph with n
vertices and 1 edge requires Ω(n2 ) queries. In light of these observations, all non-trivial algorithmic
results on graph reconstruction focus on connected bounded degree graphs.
    Mathieu et al. [MZ13] [KMZ18] showed that general bounded-degree graphs can be recon-
structed using O e∆ (n3/2 ) expected queries via a randomized algorithm.1 . This is still the best
known general upper bound today. It is unknown whether there exists a deterministic algorithm to
reconstruct a bounded-degree graph in O e∆ (n3/2 ) queries. Mathieu et al. further described a random-
ized algorithm that reconstructs chordal graphs using only O∆ (n log3 n) queries. Building on this,
Bastide and Groenland [BG24a] strengthened their result by obtaining a reconstruction algorithm
for bounded degree k-chordal graphs with O∆,k (n log n) queries (See also Rong et al. [RLYW21] for
other nearly linear reconstruction algorithms of nearly chordal graphs).2
    In a more recent work, Bastide and Groenland [BG24b] describe a randomized O∆,τ (n log2 n)-
query algorithm for reconstructing graphs with treelength at most τ . Note that bounded chordality
implies bounded treelength [DG07], but the converse is not true. Thus, their latter result applies
to a broader class of graphs, though the algorithm is slightly slower and randomized.
    In this paper, we present a deterministic O∆,τ (n log n)-query algorithm for reconstructing graphs
of bounded degree ∆ and treelength at most τ –our algorithm is deterministic and more efficient by
a factor of log n compared to Bastide and Groenland [BG24b].
Theorem 1. Given a hidden graph G, and an integer τ ≥ tl(G), there is an algorithm that
reconstructs G using at most O(∆3τ +2 · n log n) SP queries, where n is the number of vertices in G
and ∆ is its maximum degree.
    In particular, our result implies a deterministic O∆,k (n log n)-query algorithm for reconstructing
bounded degree graphs with bounded chordality, matching the optimal result for reconstructing
graphs with bounded k-chordality [BG24a]. Note that this theorem assumes that the parameter τ
is given.


2     Background and notation
In this paper, all graphs are simple, connected, unweighted and undirected. For a graph G = (V, E)
and vertices u, v ∈ V (G), we use dG (u, v) to denote the length of the shortest path between u and
v in G. For a graph G = (V, E) and a vertex v ∈ V (G), we use NG (v) to denote the set of all
neighbors of v in the graph G and NG [v] = NG (v) ∪ {v}, the open and closed neighborhood of v
respectively. Analogously, for a graph G = (V, E) and a set S ⊆ V (G), we let NG [S] = {u ∈ V (G) |
∃a ∈ S, dG (a, u) ≤ 1} and NG (S) = NG [S] \ S be the closed neighborhood and open neighborhood
of S in G respectively. For a graph G = (V, E) and a path π = v0 v1 . . . vk in G, we use π[vi , vj ]
to denote the subpath of π starting at vi and ending at vj for 0 ≤ i ≤ j ≤ k. Further, we denote
the concatenation of paths π = π0 , . . . , πn and ρ = ρ0 , . . . , ρm where πn = ρ0 in graph G with
π ◦ ρ = π0 , . . . , πn , . . . , ρn resulting in a π0 -ρn walk in G.

bag. More generally, the treelength of a chordal graph is one, and of a k-chordal graph is O(k).

The layering tree. A key tool that our algorithm uses is the notion of layering tree as used
by Chepoi and Dragan [CD00]. A similar notion has appeared in the literature of graph theory,
computational geometry, and topology under different names such as merge tree, join tree or split
tree (see these references: [CSA03, WWW14]).
     Let G = (V, E) be a connected graph, and let s ∈ V be an arbitrary vertex. We define
Breath First Search (BFS) layers Li to be the set of vertices at shortest path distance i from s,
i.e. Li = {v | dG (s, v) = i}. In particular, L0 = {s}. We use notations, L≤k := L0 ∪ . . . ∪ Lk , and
L≥k := Lk ∪ . . . ∪ Ln−1 .
     For any i ≥ 0, let Si = {Si1 , . . . , Sisi } be the set of connected components of G \ L≤i−1 , noting
that L−1 = ∅. In turn, for any 1 ≤ j ≤ si , let Pij = Sij ∩ Li , the set of vertices in Sij that belong
to Li . We call the elements of Pi = {Pi1 , . . . , Pisi } the parts of G at layer

parts partition Li . Moreover, the set of all parts (across all layers), P = 0≤i Pi , partitions V (G).
     We define the layering tree T = (P, E) of G with respect to s to be the graph whose vertices
are the parts of G. For two parts P, P ′ ∈ P, (P, P ′ ) ∈ E if and only if there exists u ∈ P and
u′ ∈ P ′ such that (u, u′ ) ∈ E(G).

3     Reconstruction Algorithm
Let G = (V, E) be a hidden graph with a visible vertex set of cardinality n and with a shortest path
distance oracle. Our algorithm first selects an arbitrary vertex s ∈ V (G) and uses n − 1 queries to
find dG (s, v) for all v ∈ V (G) \ {s}. Based on this information, our algorithm can build the BFS
layers L0 , L1 , . . . , Ln−1 .
    Next, our algorithm reconstructs G layer by layer. Specifically, for each vertex v ∈ Li our
algorithm uses SP queries to find the neighbors of v in Li ∪ Li−1 .
    Let Gi = G[L≤i−1 ] be the subgraph of G induced by the first i layers. Also, recall that T is the
layering tree rooted at s, and let ℓ be an upper bound on its length, i.e. ℓ ≥ ℓ(T ). Similarly, let Tk
be the subtree of T induced by the first k = i − ℓ − 2 layers of T , the layering tree. Our algorithm
alternates between extending Gi to Gi+1 and Tk to Tk+1 . Specifically, given Gi , we construct Tk with
no shortest path queries. Then, given Tk and Gi , we construct Gi+1 with |Li | · ∆O(ℓ) · log n shortest
path queries. Our latter algorithm is composed of a binary search type algorithm in Tk and an
exhaustive search within layers k to i, which is similar in spirit to Bastide and Groenland [BG24a]
reconstruction for k-chordal graphs.

then u and v belong to the same part at layer k; in particular, if there exists a u-v path within the

Lemma 3. Let G = (V, E), let T = (P, E) be a layering tree of G, and let ℓ ≥ ℓ(T ). Suppose
u, v ∈ V (G) belong to the same part P of T at layer k. Then, there is a path between u and v in
G whose vertices are in L≤k+ℓ+1 ∩ L≥k , i.e. u and v are connected in G \ (L≤k−1 ∪ L≥k+ℓ+2 ).

Proof. Suppose there is no u-v path in G \ (L≤k−1 ∪ L≥k+ℓ+2 ). Since u, v ∈ P , by definition there
exists a u-v path in G \ L≤k−1 . Let π be a shortest such u-v path. Then π has a vertex t in Lk+ℓ+2 .
Let µ = ⌊ 2ℓ ⌋, and let x be the last vertex in Lk+µ on the subpath π[u, t] and y be the first vertex
in Lk+µ on the subpath π[t, v]. Note that x and y are both in Lk+µ and there exists a path π[x, y]
in G \ L≤k+µ−1 that is composed of π[x, t] and π[t, y], both in G \ L≤k+µ−1 . Therefore, x and y
belong to the same part of T . It follows that dG (x, y) ≤ ℓ(T ) ≤ ℓ, as the diameter of each part is
at most ℓ.
    By definition of π, the path F := π[x, t] ◦ π[t, y] is a shortest x-y path whose vertices are in L≥k .
Thus, any x-y path either has length at least the length of F or contains a vertex of layer Lk−1 .
That is, dG (x, y) ≥ min{2(ℓ + 2 − µ), 2(µ + 1)} ≥ ℓ + 1, a contradiction.

    We use Lemma 3 to construct Tk from Gi . Note that to construct Tk , one only needs to be able
to check if a pair of vertices u, v ∈ Lk are connected in the graph G \ L≤k−1 . By Lemma 3, to check
this connectivity we only need to consider Gi .

Corollary 1. Let G = (V, E), and let T = (P, E) be a layering tree of G. For any i ≥ ℓ(T ) + 2
and k ≤ i − ℓ(T ) − 2, there is an algorithm to compute Tk from Gi (and no more information about
G) with no shortest path queries.

3.2    Extending graph reconstruction
Next, we show we can reconstruct Gi+1 given Gi and Tk for k = i − ℓ − 2. That is, we can find
all the edges that are in Gi+1 but not in Gi , namely the edges with both endpoints in Li+1 or one
endpoint in Li and one in Li+1 .
     Our algorithm takes two steps to achieve this reconstruction. First, for each vertex v ∈ Li ,
it finds the connected component of v in G \ L≤k−1 ; more specifically, the part at layer k that
is the ancestor (in the partially constructed layering tree Tk ) of the part that contains v. This
step requires ∆O(ℓ) · log n shortest path queries. Once this connected component is discovered, our
algorithm exhaustively searches for all neighbors of v within this connected component at layers Li
and Li−1 to find all its neighbors. This step takes ∆O(ℓ) queries per vertex in Li .
     To prepare for a more formal description of our method, we provide a few definitions:
   • For a vertex v ∈ V (G), we define part(v) to be the part of the layering tree T that contains
     v. Note that for any vertex v ∈ L≤k−1 , the vertex of Tk which contains v is equivalent to
     part(v), so we will use part(v) for such vertices v despite possibly not having reconstructed
     T.

   • For a vertex v ∈ Li and an integer k ∈ {0, 1, . . . , i}, we define anc(v, k) to be the part of T that
     is the ancestor of part(v) at depth k e.g. anc(v, i) = part(v), and anc(v, 0) = part(s) = {s},
     where s is the root of the BFS tree.

   • For a part P of T , we define comp(P ) to be the subset of vertices contained in P and all of
     the descendants of P in T . That is, the subset of V (G) that is contained in the subtree of
     T rooted at P . Note, if P is a part at layer k then comp(P ) is the connected component of
     G \ L≤k−1 that contains the vertices in P .

Brute force search to find neighbors. So far, we have computed comp(P ) ∩ L≤i for all P at
depth k. We bound the size of each of these vertex sets.

Lemma 7. Let G = (V, E), let T = (P, E) be a layering tree of G, and let ℓ ≥ ℓ(T ). Also, let

Proof. Each vertex in comp(P ) ∩ L≤i is at distance at most i − k from a vertex in P . Since the
graph has maximum degree ∆, it follows that there are at most |P | · ∆i−k+1 such vertices. By
Lemma 1, |P | ≤ ∆ℓ+1 , which implies the bound of the lemma.

3.3   Proof of the main result
Finally, we are ready to prove our main result.

Proof of Theorem 1. First, we select an arbitrary vertex s in V (G) and we query the distance from
s to every v ∈ V (G) \ {s} to build the layers L0 , . . . , Ln−1 ; this takes n − 1 queries. Let T be
the layering tree of G rooted at {s} (note, we have not yet computed T ). By Lemma 2, we know
ℓ(T ) ≤ 3tl(G). We set ℓ := 3τ ≥ 3tl(G), where τ is from the theorem statement. Hence ℓ ≥ ℓ(T ).
    We compute Gℓ+2 by querying every pair of vertices in L≤ℓ+1 , taking at most ∆2ℓ+4 queries.
    For i ≥ ℓ + 2, we compute Gi+1 from Gi in two steps. First, we compute Tk for k = i − (ℓ + 2),
using no queries, by the algorithm of Corollary 1. Then, by Lemma 8, we compute Gi+1 using at
most |Li |(∆ℓ+2 · log n + ∆4ℓ+8 ) queries. Summing over all remaining layers, this quantity is at most
n(∆ℓ+2 · log n + ∆4ℓ+8 ). Therefore, we reconstruct G with at most

                           n − 1 + ∆2ℓ+4 + n(∆ℓ+2 · log n + ∆4ℓ+8 )
                                 = O(∆ℓ+2 · n log n) = O(∆3τ +2 · n log n)

queries.
