12         Abstract
13   Submodular functions are fundamental to combinatorial optimization. Many interesting problems can
14   be formulated as special cases of problems involving submodular functions. In this work, we consider
15   the problem of approximating symmetric submodular functions everywhere using hypergraph cut
16   functions. Devanur, Dughmi, Schwartz, Sharma, and Singh [5] showed that symmetric submodular
17   functions over n-element ground sets cannot be approximated within (n/8)-factor using a graph cut
18   function and raised the question of approximating them using hypergraph cut functions. Our main
19   result is that there exist symmetric submodular functions over n-element ground sets that cannot
20   be approximated within a o(n1/3 / log2 n)-factor using a hypergraph cut function. On the positive
21   side, we show that symmetrized concave linear functions and symmetrized rank functions of uniform
22   matroids and partition matroids can be constant-approximated using hypergraph cut functions.

29    1      Introduction
30   A set function f : 2V → R≥0 defined over a ground set V is submodular if f (A) + f (B) ≥
31   f (A ∩ B) + f (A ∪ B) for all subsets A, B ⊆ V and is symmetric if f (A) = f (V − A) for
32   all subsets A ⊆ V . Submodular functions have the diminishing marginal returns property
33   which arise frequently in economic and game theoretic contexts. Well-known examples of
34   submodular functions include matroid rank functions and graph/hypergraph cut functions.
35   Owing to these connections, submodular functions play a fundamental role in combinatorial
36   optimization.
37       Throughout this work, we will be interested in non-negative set functions f : 2V → R≥0
38   with f (∅) = 0. We use n to denote the size of the ground set V . For a parameter α ≥ 1, a
39   set function g : 2V → R≥0 is said to α-approximate a set function f : 2V → R≥0 if
40        g(A) ≤ f (A) ≤ αg(A) ∀ A ⊆ V.
41   Given the prevalence of submodular functions in combinatorial optimization, a natural
42   question that has been studied is whether an arbitrary submodular set function can be

       77       The structural approximation question of whether every symmetric submodular function
       78   is constant-hypergraph-approximable was raised by Devanur, Dughmi, Shwartz, Sharma, and
       79   Singh [5]. They showed that every symmetric submodular function on a ground set of size n
       80   is O(n)-graph-approximable and that this factor is tight for graph-approximability: in fact,
       81   the cut function of the n-vertex hypergraph containing a single hyperedge that contains all
       82   vertices cannot be (n/4 − ϵ)-approximated by a graph cut function for all constant ϵ > 0.
       83   This example naturally raises the following intriguing conjecture:

       84   ▶ Conjecture 1. Every symmetric submodular function is constant-hypergraph-approximable.

       85   The conjecture is further fueled by the fact that there are no natural examples of symmetric
       86   submodular functions besides hypergraph cut functions (although arbitrary submodular
       87   functions can be symmetrized while preserving submodularity).

103   The symmetrization of a set function f : 2V → R is the function fsym : 2V → R obtained as

104      fsym (A) := f (A) + f (V \ A) − f (V ) − f (∅).

       145       Theorem 5 gives a concrete class of functions for which there is a large gap between the
       146   approximation capabilities of graph cut functions and hypergraph cut functions. Consider
       147   the uniform matroid where the independent sets are those of size at most 1. The symmetrized
       148   rank function of this matroid is the same as the cut function of a hypergraph with a single
       149   hyperedge spanning all vertices. As mentioned above, this function cannot be (n/4 − ϵ)-
       150   approximated by a graph cut function for all constant ϵ > 0 [5]. Thus, symmetrized rank
       151   functions of uniform and partition matroids cannot be better than n/4 approximated by
       152   graph cut functions, but can be constant factor approximated by hypergraph cut functions.
       153       While our lower bound result in Theorem 3 rules out α-hypergraph-approximability for
       154   symmetric submodular functions for α = o(n1/3 / log2 n), our positive results suggest broad
       155   families of symmetric submodular functions which are constant-hypergraph-approximable.
       156   It would be interesting to characterize the family of symmetric submodular functions that
       157   are constant-hypergraph-approximable. We also do not know if our lower bound result in
       158   Theorem 3 is tight. We only know that every symmetric submodular function is (n − 1)-
       159   graph-approximable. It would be interesting to show that every symmetric submodular
       160   function is Õ(n1/3 )-hypergraph-approximable—we believe that Proposition 2 and Theorem 4
       161   should help towards achieving this approximation factor.


       162   1.2    Preliminaries
       163   A set function f : 2V → R≥0 is submodular if f (A) + f (B) ≥ f (A ∩ B) + f (A ∪ B) for all
       164   subsets A, B ⊆ V , symmetric if f (A) = f (V − A) for all subsets A ⊆ V , and monotone if
       165   f (B) ≥ f (A) for all subsets A ⊆ B ⊆ V .
       166       A matroid M = (V, I) is specified by a ground set V and a collection I ⊆ 2V , known as
       167   independent sets, satisfying the three independent set axioms: (1) ∅ ∈ I, (2) if B ∈ I, then
       168   A ∈ I for every A ⊆ B, and (3) if A, B ∈ I with |B| > |A|, then there exists an element
       169   v ∈ B \ A such that A ∪ {v} ∈ I. The rank function r : 2V → Z≥0 of a matroid M = (V, I)
       170   is defined as

       171      r(A) := max{|S| : S ⊆ A, S ∈ I} ∀ A ⊆ V.
      C. Beideman, K. Chandrasekaran, C. Chekuri, and C. Xu                                             20:5


172   The definition of matroid rank functions that we presented in Section 1.1 is equivalent to this
173   definition [10]. It is well-known that the rank function of a matroid is monotone submodular.
174         We consider two matroids over the ground set V . A uniform matroid is a matroid in
175   which the independent sets are exactly the sets containing at most k elements of the ground
176   set V , for some fixed integer k—we call it as the uniform matroid over ground set V with
177   budget k. Partition matroids generalize uniform matroids: the independent sets of the
178   partition matroid associated with a partition P1 , . . . , Pt of the ground set V with budgets
179   b1 , . . . , bt ∈ Z≥0 are those subsets A ⊆ V for which |A ∩ Pi | ≤ bi for every i ∈ [t].
180         The proof of our lower bound will use the following theorem showing the existence of
181   cut-sparsifiers.

182   ▶ Theorem 6. [4] For every positive constant ϵ and for every weighted n-vertex hypergraph
183   H, there exists another weighted hypergraph H ′ (called a cut-sparsifier) on the same vertex
184   set with Õ(n/ϵ2 ) hyperedges such that the cut function of H ′ (1 + ϵ)-approximates the cut
185   function of H.

340    3      Upper Bounds
341   In this section, we show that certain subfamilies of symmetric submodular functions are
342   constant-hypergraph-approximable. In particular, we show how to approximate concave
343   linear functions and symmetrized rank functions of uniform and partition matroids using
344   hypergraph cut functions.

345   3.1     Concave Functions
346   In this section, we prove Theorem 4. We recall that a set function f : 2V → R≥0 is a concave

    542    4      Conclusion
    543   In this work, we investigated the approximability of symmetric submodular functions using
    544   hypergraph cut functions. We proved that it suffices to understand the approximability of
    545   symmetrized matroid rank functions. On the upper bound side, we showed that symmetrized
    546   concave linear functions and symmetrized rank functions of uniform and partition matroids
    547   are constant-approximable using hypergraph cut functions. Our upper bounds for uniform
    548   and partition matroids raise the question of whether symmetrized rank functions of constant-
    549   depth laminar matroids are constant-approximable using hypergraph cut functions. On
    550   the lower bound side, we showed that there exist symmetrized matroid rank functions on
    551   n-element ground sets that cannot be o(n1/3 / log2 n)-approximated using hypergraph cut
    552   functions, thus ruling out constant-approximability of symmetric submodular functions using
    553   hypergraph cut functions. Our results raise the natural open question of whether every
                                                                       √
    554   symmetric submodular function on n-element ground set is O( n)-hypergraph approximable.

555       Our strong lower bound also raises the question of whether we could trade off approximability
556   against the number of vertices in the hypergraph. In particular, for every symmetric
557   submodular function f : 2V → R+ defined over a n-element ground set V , does there
                                                                                 ′
558   exist a hypergraph over a vertex set V ′ ⊇ V with cut function d : 2V → R≥0 such that
559   d(A) ≤ f (A) ≤ αd(A) for every A ⊆ V , where α = O(1) and |V ′ | = O(2n )?
