Derandomization? The results in the two SODA’17 papers naturally raise the question of whether there
exists a deterministic O(t)-time
                        e         algorithm for subset sum, and this question has remained open for the last
8 years. Bringmann’s randomized algorithm uses a color-coding technique [AYZ95], and although some
past algorithms based on color-coding have been successfully derandomized (e.g., for computing k-simple
paths/cycles in graphs), the overhead for derandomizing color-coding seems too big for the application to
subset sum (our desired O(t)
                           e bound doesn’t leave much room to absorb the overhead). If the number of
elements k allowed in a sum is sublogarithmic, the cost of derandomization is tolerable, but not when k is
large. It is unclear how to apply standard techniques such as the method of limited independence or the
method of conditional probabilities/expectations without blowing up the time bound. Jin and Wu’s alter-
native randomized algorithm [JW19] seems even tougher to derandomize—it computes counts modulo a
random prime, and there is no obvious efficient way to guarantee that a correct prime is selected. Just con-
verting these Monte Carlo randomized algorithms to Las Vegas is already open. On the other hand, Koiliaris
and Xu’s deterministic approach [KX19] (see also [KX18] for an alternative) seems difficult to improve
upon—they did give a variant with O(t e 4/3 ) running time but there is no clear path towards O(t1+ε ). By
contrast, for variants such as unbounded subset sum2 [Bri17] and modular subset sum [ABB+ 21], efficient
derandomization is not as difficult and is already known.

New algorithm. We present the first deterministic algorithm for subset sum running in O(t)     e time. It also
solves the all-targets version of the problem.
    Our algorithm may be viewed as a derandomization of a variant of Bringmann’s [Bri17]. Instead of
partitioning the input set into multiple disjoint subsets via color-coding, we recursivly partition the input
set into two subsets, in such a way that the desired√subset for each target is split roughly evenly into two
halves in terms of their cardinalities (with about k additive error if the subset has about k elements).
This reinterpretation of Bringman’s algorithm as a divide-and-conquer via “halvers” (or similar randomized
partitioning) is not new, and has appeared in other subsequent randomized algorithms for subset sum and
knapsack (e.g., see [BN20, BDP24, BFN25]). However, although the existence of a good halver is guaran-
teed by the probabilistic method (via standard Chernoff or discrepancy bound), its deterministic construction
seems to require knowing the subsets for all targets, i.e., knowing all the answers in the first place! Our new
approach is to speed up the halver construction by worsening its quality.3 So long as the additive error is
kept slightly sublinear (bounded by k/ log k), the divide-and-conquer would still be efficient. To this end,
we show that for any subset, there is an equivalent subset (with the same sum) that can be divided into
a sublinear number of small “canonical” subsets; we then naively construct a halver with respect to these

2.2    Halver
The key idea behind our algorithm concerns the construction of a halver, which we define below:

Definition 2.2. Given a set X of positive integers, and numbers k and ∆, a (k, ∆)-halver of X is a partition
of X into two disjoint subsets X ′ and X ′′ with the following property:

       For every subset S ⊆ X with |S| ≤ k, there exists a subset Ŝ ⊆ X with |Ŝ| ≤ k, σ(Ŝ) = σ(S),
       and |Ŝ ∩ X ′ |, |Ŝ ∩ X ′′ | ≤ |Ŝ|/2 + ∆.

    Note the slight subtlety with the existential quantifier in the above definition (since there could be multi-
ple subsets with the same cardinality and the same sum as S). We recall a well-known fact from discrepancy
theory:

Lemma 2.3. Given a set X and a collection C of subsets of X each of size at most k,pwe can compute a
partition of X into two subsets X ′ and X ′′ such that |S ∩ X ′ |, |S ∩ X ′′ | ≤ |S|/2 + O( |S| log |C|) for all
S ∈ C, in O(k|C| + |X|) deterministic time.

then follows by summing over all i ∈ [k].

4     Remarks
In the O(t)-time
        e          algorithm in Section 2, we have not tried to optimize (and thus have not written out) the
number of log t factors. It is larger than the previous randomized algorithms (Bringmann’s algorithm [Bri17]
had 4 log factors, and Jin and Wu’s algorithm [JW19] had 2), but is not gigantic (probably below 20).
    In the output-sensitive algorithms in Section 3, we reiterate that the hidden extra factors are polylogarith-
mic in n and t. The previous randomized algorithms by Bringmann, Fischer, and Nakos [BFN25] actually
got factors that are polylogarithmic in the output size |Σ(X) ∩ [t]| rather than in t; this seems harder to do
from the derandomization perspective (but would not make a big difference except in some extreme cases).
    Like previous work, our algorithms easily adapt to the setting when X is a multiset—a subset of X
cannot use an element more times than its original multiplicity. (Note that n could be larger than t here, and
to avoid an O(n) term in the running time, we may need to assume that X is represented as a list of distinct
elements with given multiplicities.)
    In the O(t)-time
            e          algorithm in Section 2, we generate canonical subsets by adapting Koiliaris and Xu’s
algorithm [KX19], but in Section 3, we have realized that Koiliaris and Xu’s algorithm is not essential to
our technique (though it is convenient, since it already incorporates dyadic intervals). This realization may
potentially help in future applications.

gave deterministic reductions from min-plus convolution to all-targets 0-1 knapsack. In the reverse direc-
tion, Cygan et al. [CMWW19] gave a randomized reduction from all-targets 0-1 knapsack to min-plus
convolution, by modifying Bringmann’s randomized algorithm for subset sum [Bri17]. We can obtain a
deterministic reduction from all-targets 0-1 knapsack to min-plus convolution by modifying the algorithm
in Section 2.
    The modification is mostly straightforward. We mention some of the main changes:

    • Expressions such as X ∩ I should be reinterpreted as X ∩ (I × R+ ).

    • Most occurrences of Σi (X) should be changed to P - MAX(Σi (X)).

    • Each sumset A + B should be changed to P - MAX(A + B). Given A, B ⊆ [t] × R+ , the computation
      of P - MAX(A + B) is equivalent to max-plus convolution over two real vectors of length O(t), which
      is equivalent to min-plus convolution by negation.

    • In Definition 2.2 on halvers, the property is now:

           For every subset S ⊆ X with |S| ≤ k and σ(S) ∈ P - MAX(Σ≤k (X)), there exists a subset
           Ŝ ⊆ X with |Ŝ| ≤ k, σ(Ŝ) = σ(S), and |Ŝ ∩ X ′ |, |Ŝ ∩ X ′′ | ≤ |Ŝ|/2 + ∆.

    • In Lemma 2.4 on canonical subset generation, the property is now:

           For every subset S ⊆ X with σ(S) ∈ P - MAX(Σ|S| (X)), there exists a subset Ŝ ⊆ X such
           that |Ŝ| = |S|, σ(Ŝ) = σ(S), and Ŝ is expressible as a union of O((|S|/b + 1) log u)
           disjoint canonical subsets in C.

      Note that if σ(S) ∈ P - MAX(Σ|S| (X)), then for any interval I, we must also have σ(S ∩ (I × R+ )) ∈
      P - MAX |S∩(I×R+ )| (X ∩ (I × R+ )).

    • In Lemma 2.6, we are now computing a set OUT ⊆ [ku]×R+ such that P - MAX(Σ≤k (X)) ⊆ {(w, p′ ) :
      p′ ≥ p, (w, p) ∈ OUT} and OUT ⊆ Σ(X).

The rest of the changes are easy to work out.
