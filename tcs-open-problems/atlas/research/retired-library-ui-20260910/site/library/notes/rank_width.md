## Open questions and directions in the source

1. **Question:** Can the quadratic rank-width bound on Boolean-width be replaced by a linear bound? — §2.3, Boolean-width. [PDF p. 3](../pdf/rank_width.pdf#page=3)

2. **Question:** Compute rank-width of circle graphs in polynomial time. — Question 1. [PDF p. 6](../pdf/rank_width.pdf#page=6)

3. **Question:** Approximate rank-width with parameter-dependent output width in O(c^k n³) time. — Question 2. [PDF p. 6](../pdf/rank_width.pdf#page=6)

4. **Question:** Obtain such an approximation with a subcubic dependence on n. — Question 3. [PDF p. 6](../pdf/rank_width.pdf#page=6)

5. **Question:** Compute linear rank-width by an FPT algorithm parameterized by rank-width. — §3.4, unnumbered. [PDF p. 7](../pdf/rank_width.pdf#page=7)

6. **Question:** Compute rank-width exactly in O(c^n) time for c<2. — Question 4. [PDF p. 7](../pdf/rank_width.pdf#page=7)

7. **Conjecture:** Excluding any fixed vertex-minor defines a χ-bounded graph class. — §4.3, Geelen conjecture. [PDF p. 9](../pdf/rank_width.pdf#page=9)

8. **Conjecture:** Large rank-width forces every fixed bipartite circle graph as a pivot-minor. — Question 5. [PDF p. 10](../pdf/rank_width.pdf#page=10)

9. **Question:** Does sufficiently large linear rank-width force every fixed tree as a vertex-minor? — §4.5, unnumbered. [PDF p. 10](../pdf/rank_width.pdf#page=10)

10. **Question:** Are all graphs well-quasi-ordered by pivot-minors? — Question 6. [PDF p. 11](../pdf/rank_width.pdf#page=11)

11. **Question:** Detect any fixed pivot-minor or vertex-minor in polynomial time. — Question 7. [PDF p. 11](../pdf/rank_width.pdf#page=11)
