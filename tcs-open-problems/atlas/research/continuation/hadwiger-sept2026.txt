                                          1     Introduction
                                          The chromatic number of a graph1 𝐺, denoted by 𝜒(𝐺), is the minimum 𝑘 such that 𝑉 (𝐺) can be covered by
                                          𝑘 stable sets in 𝐺, where a stable set in 𝐺 is a set of pairwise non-adjacent vertices. Bounding the chromatic
                                          number is a central topic in graph theory. For example, the Four Color Theorem [AH77, AHK77, IKMMTT,
                                          RSST97] states that every planar graph has chromatic number at most 4.
                                              Hadwiger [Had43] proposed a far-reaching generalization of the Four Color Theorem, stating that for
                                          every positive integer 𝑡, every 𝐾𝑡+1 -minor-free graph has chromatic number at most 𝑡. A graph 𝐻 is a minor
                                          of a graph 𝐺 if some graph isomorphic to 𝐻 can be obtained from a subgraph of 𝐺 by contracting edges.
                                          Wagner proved that the 𝑡 = 4 case is equivalent to the Four Color Theorem [W37]. Robertson, Seymour, and
                                          Thomas [RST93] further proved the 𝑡 = 5 case. Hadwiger’s conjecture remains open for 𝑡 ≥ 6.
                                              Kostochka [Kos82,

                                          𝐾𝑡 -minor is 𝑂 (𝑡 log 𝑡)-degenerate and hence has chromatic number 𝑂 (𝑡 log 𝑡). The degeneracy bound
                                          proved by Kostochka and Thomason is optimal [Kos82, Kos84, F83], and the resulting bound on the chromatic
                                          number remained the best known for decades. Breaking the barrier for this degeneracy bound, Norin,

                                          𝐾𝑡 -minor-free graph has chromatic number 𝑂 (𝑡 (log 𝑡) 𝛽 ) for every fixed 𝛽 > 1/4. Delcourt and Postle [DP25]

so in fact we only need to try to reduce the number of high degree vertices. This suggests that we should
repeat this contraction process while only focusing on those high degree vertices.
