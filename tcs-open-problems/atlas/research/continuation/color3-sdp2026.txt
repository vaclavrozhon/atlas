1        Introduction
We study the problem of coloring a 3-colorable graph with the fewest number of colors in polynomial
time. It is one of the most classical tasks in theoretical computer science that has been extensively
studied in both algorithm design and complexity theory for decades, but there is still a wide gap
in our understanding.
On the hardness side, coloring 3-colorable graphs with three colors was proved to be NP-hard
in 1974 [GJS74]. Ruling out four colors took place in the 90s [KLS00, GK04]. Using heavy
algebraic machinery from Promise CSPs, Barto, Bulı́n, Krokhin, and Opršal [BBKO21] proved
that coloring 3-colorable graphs using 5 colors is NP-hard, which remains the best known hardness
result assuming only P ̸= NP. Assuming variants of the Unique Games Conjecture, NP-hardness
was established for any constant number of colors greater than three [DMR09, GS20, BKLM22].
On the algorithmic front, there have been nice parallel developments from combinatorial meth-
ods and semidefinite programming (SDP) methods. From the combinatorial side, the well-known

1.1        Overview of Our Result
Our main contribution in this paper is achieving the first progress on the SDP-based approach since
Chlamtáč [Chl07], resulting in the following theorem.
Theorem 1.1. There is a polynomial time algorithm which, given a 3-colorable graph G, produces
a proper coloring with O(n0.19539 ) colors.
We now present a high-level overview of our result. To better do so, we first give an overview
of previous SDP algorithms and their combination with combinatorial algorithms. As mentioned
earlier, the current best approach for coloring 3-colorable graphs uses a two-pronged attack, namely
combinatorial algorithms which work well on dense graphs, and SDP-based algorithms which work
well on sparse graphs. It is known that in order to obtain an f (n)-coloring, it is sufficient to
find some ∆ = ∆(n), and make progress towards an f (n)-coloring separately with two families of
graphs: those whose maximum degree is at most ∆ (the sparse case), and those whose minimum
degree is at least ∆ (the dense case). (See Section 2.2 for a formal definition of making progress.)
On the combinatorial side, the current best result is the following theorem.

of the first cover (recall that efficiency measures how many more vectors are in the cover than

         √ a priori doesn’t have any guarantee on it. As a result, we may lose a lot in the error
term O( c′ t) and not gain any advantage over the second-level analysis.
We get around this issue by using a “win-win” argument. Note that if c′ is indeed too large for cover
composition, then it means that the two-step cover is very inefficient, in the sense that it contains
many more vectors than the pessimistic estimate from the union bound. This already yields an
improvement over the second-level analysis, as now we have a lot more vertices in N (2) (i), on which
we can then apply the same vector 2-coloring argument as before and extract an independent set
whose size is meaningfully larger than the previous analysis estimates it to be. On the other hand,
if c′ is small, then we can apply cover composition without too much loss, which would show that
N (3) (i) grows significantly over N (2) (i). This is the main focus of Section 5.2.
The third challenge is that, unlike on the second level, we can no longer define a vector 2-coloring
for typical vertices on the third-level neighborhood. This was what enabled us to extract a large
independent set from the second-level neighborhood. To overcome this, we design a new vector
5/2-coloring on N (3) (i), which we highlight next. This new vector 5/2-coloring would allow us to
obtain an independent set of size ≈ |N (3) (i)| · ∆−1/5 (using Theorem 2.3). This ∆−1/5 loss term is
easily compensated by the gain in the size of N (3) (i), thereby completing the argument.

1.2    Other Related Work
Coloring 3-colorable graphs is a special case of the approximate graph coloring (AGC) problem,
where the goal is to color c-colorable graphs with d colors, for some 3 ≤ c ≤ d. AGC is an
important, perhaps most prominent, example of promise constraint satisfaction problems (Promise
CSP). Recent advancements in the study of Promise CSPs have led to the strongest known NP-
hardness results for AGC. For c = 3, Barto, Bulı́n, Krokhin, and Opršal [BBKO21] proved NP-
hardness for d = 5. For c ≥ 4, Krokhin, Opršal, Wrochna, and Živný [KOWŽ23] established

                                                     5
                         c
                           
NP-hardness for d =    ⌊c/2⌋   − 1. It is also known that some powerful hierarchy-based algorithms
cannot solve AGC for any 3 ≤ c ≤ d [CŽ25].
For almost coloring (i.e., one needs to color only (1 − ε) fraction of vertices for constant ε > 0),
stronger hardness results are known [DHSV15], most notably the NP-hardness of distinguishing
4-almost-colorable graphs and c-almost-colorable graphs for any constant c, based on the 2-to-2
Game Theorem [KMS17, DKK+ 18, KMS23].
Given the difficulty for worst case instances, another interesting line of work has focused on algo-
rithms for 3-colorable graphs that satisfy additional structural guarantees, such as for planted and
(semi-)random models [BS95, AK97, FK01], or graphs with expansion properties and low threshold
ranks [AG11, DF16, KLT17, BHK25, Hsi26].

Here the variable X(i,C) serves as the indicator of “i takes color C”. The first constraint enforces
that each variable i ∈ V picks exactly one color, and the second constraint makes sure that the two
endpoints of an edge do not take the same color. We now relax it to the following semi-definite
program. Let k > 0 be an integer. For any S ⊆ V × {R, G, B} with |S| ≤ k, we have a vector-valued
variable vS . These vectors satisfy the following equations:

  ∥v∅ ∥ = 1,
  v(i,R) + v(i,G) + v(i,B) = v∅ ,   ∀i ∈ V,
  v(i,C) · v(i,C′ ) = 0,            ∀i ∈ V, C, C′ ∈ {R, G, B}, C ̸= C′ ,
  v(i,C) · v(j,C) = 0,              ∀{i, j} ∈ E, C ∈ {R, G, B},
  vS1 · vS2 = vS3 · vS4 ,           ∀S1 , S2 , S3 , S4 ⊆ V × {R, G, B}, S1 ∪ S2 = S3 ∪ S4 , |S1 ∪ S2 | ≤ k.

This is called the k-round Sum-of-Squares(SoS)/Lasserre relaxation. As long as k is a constant, this
SDP has polynomial size, so it can be solved in polynomial time. One very helpful intuitive interpre-
tation of these vectors is via local distributions. The SDP computes, for each S ⊆ V ×{R, G, B} with
|S| ≤ k, some distribution over {X(i,C) | (i, C) ∈ S}, which we call the local distributions. These
local distributions satisfy consistency requirements, namely for any S1 and S2 with S1 ∩ S2 ̸= ∅,
the marginals of their local distributions on S1 ∩ S2 should be the same. It is sometimes useful to
imagine that these local distributions were marginals of some global distribution over the entire set
{X(i,C) | (i, C) ∈ V × {R, G, B}}, though we should keep in mind that this global distribution may
not necessarily exist.
The interpretation of these inner products using the local distributions is that for any S1 , S2 ,

                                vS1 · vS2 = Pr[∀(i, C) ∈ S1 ∪ S2 , i = C],

where the probability on the right hand side is over the local distribution and we use i = C to mean
X(i,C) = 1 (i.e., i takes color C), slightly abusing the notation.
Observe that due to the symmetry between the three colors, we may further impose that the inner
products between these vectors are preserved up to permutation of the colors. In particular, this
implies that for every i ∈ V and C ∈ {R, G, B}, ∥v(i,C) ∥2 = Pr[i = C] = 13 . This will be assumed in
the remainder of this paper.

5    Analyzing Third-Level Neighborhoods
In this section, we extend the analysis in the previous section to third-level neighborhoods. The
overall idea is to show that there exists some vertex i whose third level neighborhood N (3) (i) is
sufficiently “random-like”, in the sense that for a “generic” ℓ ∈ N (3) (i), we have vi · vℓ ≈ (−1/2)3 =
−1/8. Using Lemma 3.2, we can obtain a vector (≈) 25 -coloring of these vertices, on which we can
then apply the KMS algorithm and obtain an independent set of size roughly Ω(|N (3) (i)|·∆(G)−1/5 ).
This plan of attack comes with two technical challenges:
    • It is crucial to bound how much vi · vℓ actually differs from −1/8. Using a naive bound
                                                                    √
      without pruning, one can show that vi · vℓ = −1/8 + Θ( c) for a “generic” ℓ ∈ N (3) (i).
      However, this loss translates poorly to the loss in vector chromatic number that we obtain
                                                                       √
      from Lemma 3.2. Indeed, even for mildly big c = 0.01, the Θ( c) term can easily push the
      inner product to 0, in which case the vector coloring we obtain reduces to a vector 3-coloring
      and no progress can be made. It is therefore essential to extend the pruning technique from
      two-step walks to three-step walks, which will give us vi · vℓ = −1/8 + Θ(c). This is the focus
      of Section 5.1.
    • We also want the number of such “generic” vertices in N (3) (i) to be large. In fact, we
      need it to be much bigger than the second-level neighborhood, in order to overcome the
      loss from the term ∆(G)−1/5 which is introduced because we go from a vector 2-coloring
      on the second-level to a vector 25 -coloring on the third-level. This analysis requires us to
      compose the two-step cover on the second-level with an extra step, using the cover composition
      lemma (Lemma 4.14). However, the loss term in the cover composition lemma depends on
      the efficiency of the two-step cover, and if it is very inefficient, then we may not get any
      improvement at all! This might look bad at first glance, but a moment of thought reveals
      that we are in fact in a win-win situation, namely, if the two-step cover is very inefficient,
      then it means it has a lot more vertices than the estimate in Theorem 4.2, which implies that
      we already have an improvement; otherwise, it is efficient enough and we do make meaningful
      progress in the third-level neighborhood. This analysis is carried out in detail in Section 5.2.

6    Conclusion
In this paper, we presented an O(n0.19539 )-coloring algorithm for 3-colorable graphs, improving the
state of the art on SDP-based approaches. We conclude with some directions for future work.
    • The main loss term in the current analysis is incurred by the cover composition lemma
      (Lemma 4.14), where the analysis uses Gaussian isoperimetry which is only tight for half-
      spaces. However, for covers the geometry seems very different from half-spaces which gives
      hope for improvement. Indeed, Arora, Chlamtáč, and Charikar [ACC06] proposed the fol-
      lowing conjecture, which if true would provide improved parameters in the cover composition
      lemma:
      Conjecture 1 (Conjecture 1 in [ACC06]). For any (s, δ)-cover {ui }ki=1 , if {vi }ki=1 are mutu-
      ally equidistant unit vectors which also form an (s, δ)-cover, then for any ρ ≥ 0

                             Pr[max r · ui ≤ s − ρ] ≤ Pr[max r · vi ≤ s − ρ].
                                    i                      i


    • The most natural next step of work is perhaps to extend the analysis further to four steps.
      We believe this can be done. However, without improving the loss term discussed in the
      previous item, the potential gain from this would likely be more technical trouble than it’s
      worth.
    • It is interesting to study whether our vector 5/2-coloring may be applicable in the combina-
      torial coloring algorithms. One potential way to do so was suggested in Lemma 3.3.
